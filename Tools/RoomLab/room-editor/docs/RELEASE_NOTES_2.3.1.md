# Room Lab 2.3.1 · 2026-10-25

## 轨道子节点

选中电磁装置，打开右侧「节点图」。节点以稳定 ID 归属装置，仍保存世界格坐标，旧版 path 数据自动补齐归属。移动装置会带动所有子节点；复制房间时生成新的子节点 ID。

节点图显示顺序、方向和相对位置，可点击选择。「新增节点」直接添加；「画布加点」进入点击加点模式。画布上显示 I、II、III 等罗马数字，可选中拖动；默认吸附 0.5 格，Alt 精细到 0.01 格。坐标输入支持精确修改，提供提前、后移、删除和撤销。

## 编辑交互

「按键提示」位于「按键说明」旁，控制选择、擦除、撤销与重做按钮上的实际快捷键徽标，偏好保存在本机，不写入关卡。

选择冷热区域后显示四角控制点，拖动改变区域尺寸，按整数格吸附、保持至少一格并限制在房间内；一次拖动可一步撤销，区域 ID 和机关关联不变。

温控板「初始状态」可选择继承区域、初始冷、初始热。显式冷/热在冰块创建前统一应用，与对象摆放顺序无关。编辑预览与试玩初始颜色一致；同一区域配置互相矛盾时提示并拒绝试玩。

## 试玩路径

试玩自动记录角色中心轨迹，重试与跨房之间断开轨迹段。「保存 / 显示路径」可以命名保存本次记录；退出试玩后也可从编辑页「试玩路径」保存。经过多个房间时，分别写入对应房间。

路径按不同颜色显示，多条可同时勾选叠加；支持全选、隐藏、移除和路径 JSON 导入导出。路径随项目 JSON/项目 ZIP 保存，重新打开项目后仍可读取。单房最多 32 条路径，每条最多 12000 个采样点，长录制会自动减采样。独立路径文件要求房间尺寸匹配，读取上限为 8 MiB。
