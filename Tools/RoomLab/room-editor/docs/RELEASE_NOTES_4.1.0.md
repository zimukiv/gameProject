# Room Lab v4.1.0

完整解压 Windows 程序包后打开 `RoomLab.exe`。本版在 4.0 道具与巡查老师系统的基础上，加入入口反向返回和跨大关整房复制粘贴。

## 入口反向返回

- 从上一房间出口进入新房间后，玩家离开本次到达入口再重新碰到它，会返回上一房间中连接该入口的对应出口。
- 返回时恢复上一房间离开前的机关状态。
- 返回后的出口会先休眠，玩家离开出口区域并重新进入后才会再次正向过门，避免反复传送。
- 存档点、死亡重试和已有房间缓存会保留反向返回关系。
- 直接从某个入口开始试玩时没有来源房间，因此不会触发反向返回。

## 跨大关整房复制粘贴

- 在接线板选中房间，或直接进入房间编辑器，点击「复制整房」或按 `Ctrl+C`。
- 切换目标大关后点击「粘贴整房」或按 `Ctrl+V`，房间会作为新的独立房间追加到当前大关。
- 房间尺寸、地形、入口出口、功能对象、机关砖、温控区、素材覆盖、试玩轨迹和房间内部接线会一起复制。
- 房间、入口出口、对象、机关关联、轨道节点和轨迹 ID 会全部重新生成，避免与目标项目冲突。
- 房间引用的自定义素材会带入目标项目并归入目标大关；完全相同素材会复用。
- 跨房间接线不属于单个房间，不会自动复制，粘贴后需要重新连接。
- 粘贴作为一次项目修改可撤销；来源依赖测试版规则时会先确认是否启用。
- 剪贴板只保存在当前应用运行内存中，重启应用后清空。

## 兼容性

- 项目格式仍为 v2，4.0 项目可直接打开，无额外迁移。
- 大关、房间、接线、素材和云同步数据结构不变。
- 本次继续通过 Windows x64 便携包发布，运行时、素材与依赖需完整解压保留。
