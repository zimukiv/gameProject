# Room Lab v3.0.0

完整解压 Windows 程序包后打开 RoomLab.exe。有有效本地草稿时直接恢复；没有草稿时，可导入 JSON / ZIP 或新建三主题项目。旧项目仍按原内容打开。项目内「新建大关」加进一种主题，默认带三间连通示例房，取消勾选则只建一间空白房。

- **物理**：保留原有三个示例房，以及原机关和房间参数。
- **高数**：三个串联示例依次展示积分桥与求导门、积分拼桥、两块求导板分别控制挡路砖。选中积分板或求导板，点「快捷绑定」，再逐块点击机关砖即可绑定。同色连线显示归属。选中机关砖的「节点图」，可在画布加点、拖动，并独立设置每段用时和运动曲线。
- **水课**：三个串联示例依次展示签到与清醒、独立签到站与复活点、清醒加速跨空档。清醒板速度、上抛和冷却可编辑。

三关的示例、专属机关、配色和 AI ID 分开；项目格式仍为 v2。使用这些新增机关试玩请用 3.0.0。

大关页「新建房间」默认只放入口，地形、出口及机关可自行摆放。首页右键大关卡片可改名或删除。改名保留现有接线；删除需确认且至少保留一个大关。两者都可用 Ctrl+Z 撤销。

顶栏只保留「保存项目」「云同步」「项目」「工具」。已进入项目时，可从「项目 → 打开项目」切换到已有 JSON / ZIP。「工具」下的素材库和功能块默认选中当前大关；功能块的名称、行为参数和素材默认值只作用于该大关之后放置的同类方块。Ctrl+S 保存，Esc 收起菜单。

源码、旧版本及协作规则见仓库 Tools/RoomLab；每次修改前按 AGENTS.md 核对远端。云同步服务和 Unity 工程没有随此版本变更。
