# Room Lab 2.4.0

- 云同步提供即时协作与手动保存两种模式。即时修改只交换草稿；只有明确保存才产生工作树版本，从上次读取的云端版本建立子分支。
- 同一连接密钥供两台电脑使用，当前电脑已配置加密连接。另一端导入密钥后，下载并读取同一来源版本，再开启即时模式。服务与密钥使用见 CLOUD_SYNC。
- 新建改为「新建大关」，在现有项目追加内容；未保存时提示保存、继续或取消，保存失败不离开。
- 方块支持碰撞开关，无碰撞显示虚线。AI 实心/空心统一为一个 AI 启动板。
- 冰块不再绑定温控区。区域按几何范围影响冰块，冷热重叠时热优先；控制器单向选择区域。区外使用房间默认温度。
- 保持项目 version=2，保留原房间、素材、稳定 ID 和接线；旧 AI 别名和单区冰块参考值仍可由兼容导出供 2.3.1 读取。新碰撞覆盖、重叠区温度和云协作须双方使用 2.4。

关闭旧版后，解压整个 Windows 包，运行 RoomLab.exe。源码包同时含 room-editor 和 room-cloud；授权密钥不随包分发。原发布保留，不覆盖用户关卡。完整限制和维护入口见 CLOUD_SYNC、PROJECT_FORMAT 和 TESTING。

修复：死亡回退使用独立状态快照，AI 板不再因已使用状态污染出生点而失效；包括无碰撞 AI 板、保留状态策略，以及继承的 AI 在本房禁用后重新召回。
