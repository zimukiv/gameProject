# Room Lab 2.4.1

解压完整 Windows ZIP，运行其中的 RoomLab.exe。两端建议同时升级；保留旧项目文件与旧发布包。

- 修复导入喷气装置 2.0（direction/force）被旧主版本检查拦住，以及方向字段被忽略的问题；同时兼容 1.x 横纵速度。保存时补齐等效横纵速度，保留原参数；旧模块无法理解的主版本仍明确报错。
- 功能块数字范围改为建议，允许超范围有限数值；保留空值、非数字、无穷值与结构校验。默认定义保存保留自定义额外字段。
- 项目 settings.performance 现在实际参与运动，包括跳跃、重力、移动和冲刺参数；兼容温控 initial 旧字段。
- 新增框选工具（M），选择/框选模式下 Shift 左键追加、Shift 右键反选，点选与拖框都支持。多选整体拖动、Delete 批量删除、Esc 清空；整体移动和删除各一步撤销，清理相关端口连线，保护最后入口。
- 电磁轨道标记与文字随画布缩放；新放置装置的 0 节点在方块中心，其后为 I、II 等。旧装置节点坐标不强制重排，仍可自行调整起点；新装置按放置位置平移默认路径。
- 温控区入口移动到物理机关分组，紧邻温控板；区域显示、四角缩放和冷热行为保留。大房间及接线板最低缩放支持 1%。
- 工作树树状预览，节点可拖动调整本机关联，也可在管理中改名、选择父节点、删除和恢复。管理关系与不可变版本来源分开，不会因拖动改坏同步来源。
- 显示节点包含的大关、房间数、关联本地 JSON 和文件缺失状态；支持手动关联、解除及打开所在文件夹。同名、重复文件关联、重复下载有提示；覆盖已有 JSON 需确认，被其他程序修改会额外提示。取消覆盖不写入。
- 连接导入错误显示在弹窗顶部，未连接不能复制空密钥；旧加密配置读取失败时可重新导入修复。新增只读检查连接，区分配置与网络认证。换云工作区保留快照并清空旧工作区同步来源。
- 编辑方块后保留缩放和平移，包括放置、拖动、擦除、撤销重做、属性栏收放。房间尺寸支持 6–256 列、5–256 行，初次进入或点击适应房间才重新取景。

树上管理位置、回收站和本地绝对文件路径只存本机；云端版本内容与版本来源仍按原协议同步。本次不会自动删除云端分支。删除节点可从回收站恢复，草稿和快照保留；恢复不会重新收回已提升的子节点。

旧关卡格式保持 v2，可继续读取。超过旧版 120×80 限制的房间需新版才能校验和试玩；请让协作双方升级。试玩仍采用整房视角，大房间的角色会随整房缩放变小，可在编辑时放大设计。
