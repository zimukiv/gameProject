# 编辑器操作

## 项目 → 大关 → 房间

新建默认第一物理关。进入大关后，接线板展示房间缩略图，双击进入；拖房间标题调整排布。房间名称、备注和稳定 ID 分开，改名不影响连接。可新建、复制和删除房间，复制会重绑内部温控区/机关引用，不复制外部接线。

接线从橙色出口实心点拖到绿色入口实心点。端口位置按房间实际坐标投影到缩略图，附名称标签。一个出口只能连接一个入口，多出口可到同一入口；再次连接某出口替换旧连接。滚轮以鼠标位置为中心缩放，中键拖动画布，「查看全部」适应所有房间，「100%」恢复初始视图。缩放/平移只改变视图，不改变房间节点位置或接线数据。入口和出口方块在房间内放置，名称与备注可以修改。默认穿房间清除速度，也可选择保留速度。**未接线出口表示大关结束**。

## 房间编辑

房间右侧属性修改名称、备注、尺寸、环境、阶段与 AI ID。支持 6–256 列、5–256 行，各房间独立。缩小前显示越界预览，确认后元素保留并标红，移回界内才可试玩。

顶部横栏切换本大关房间；图标选择栏按地形、物理机关、收集与危险、入口与区域、AI 分组。点击图标后直接在画布放置，可长按拖动连续放置多个对象，跨过的格子自动补齐；窄窗口下在选择栏滚轮横向滚动。画布自适应窗口，「收起属性」进一步扩大画布。「按键说明」打开操作帮助。B 地形、V 选择、X 擦除地形及方块；拖画，Shift+拖画矩形；滚轮缩放、中键平移、「适应房间」复位。擦除可移除地形、功能对象和机关砖，并清理关联；入口/出口和温控区域先选择再「删除对象」。同格重叠时连续点击循环选中，温控区与普通方块可能重叠。

选中对象后右侧分为基础/行为/关联/外观：位置、名称、备注；机关参数与死亡回退；AI ID 或入口朝向；素材覆盖。「关联 → 从此入口试玩」可从任意命名入口开始。撤销/重做保留最近 60 次项目变更，不作为长期文件备份。

## 物理机关

- **喷气板**：x,y 为方块左上格，踩顶面触发。可设置水平/垂直发射速度、冷却、影响 AI 与范围。向上速度为负；踩踏触发。选中「需要 AI 靠近」后，玩家站住等 AI 接近该机关才触发。
- **温控板**：先画温控区域，设置尺寸与初始冷热，再在板的行为中选对应区域。空关联控制全房。可切换或固定冷/热，冷热会影响该区域关联冰块。
- **冰块**：关联同一温控区，冷态实体、热态消失。站立累计计时跨多次踩踏，达到阈值融化。冷态经过再生成间隔重建、计时归零；角色占据其格子时等待，避免穿模。减速系数越低越滑。
- **电磁轨道**：脚踩起点，沿路径从零加速，末端按角度发射。点击「在画布编辑轨道节点」逐点添加，Shift 点击删除末点，也可编辑 JSON 节点。角度 -90 朝上，0 向右；允许脱离时可跳跃或冲刺离轨。

所有关联区与节点属于房间实例，不写入全局默认值。「功能块 → 保存默认定义」只改变以后新放置实例，旧实例保留参数；改已有对象请进入其行为页面明确应用。

## 美术工作

素材库按大类 → 子类 → 素材逐层展开。例如机关 → 冰块 → 完整/裂纹图片。先进入具体子类再导入，图片自动归入当前目录；从首页导入进入「未分类」。通过「资料 / 归类」修改大类、子类、所属大关、图集帧尺寸与 FPS。支持 PNG/JPG/WebP/GIF/SVG。矩形图集按帧尺寸从左到右逐行播放。

大关「美术绑定」和对象「外观」只展示本大关或通用素材中，对应该功能块子类的图片；「本类通用」可复用于同一大类中的方块。未分类素材需要先归类。旧项目缺少分类字段时从现有绑定推断，不改 ID；不兼容的现有引用保留但不能作为新候选。替换图片保留 ID、分类、大关归属和全部绑定，行为和碰撞不受图片大小影响；删除素材会保留缺失引用并显示占位，可撤销。

## 保存与试玩

保存 JSON 同时保存相对 assets 目录。移动工程时一起移动两者；发队友请导出 ZIP，导入 ZIP 后另存 JSON。保留独立备份，不用浏览器草稿代替交付文件。

试玩房间整幅显示，尺寸较大时会缩小画面。画布自适应窗口，默认收起状态栏，点击「显示状态」可测试 AI 近/远，用于验证条件机关；实际 AI 技能未制作。暂停冻结物理计时，重试回当前入口。三房示例可直接从首房试玩贯通，但它是机关教学/验证，不代表最终比赛难度。

AI 启动板提供实心（可以站立、踩顶面触发）和空心（无碰撞、经过触发）两种版本。旧项目的 AI 启动板沿用实心 ID。

## 2.3.1 节点、区域与试玩路径

电磁装置右侧新增「节点图」，用缩略图或列表选择子节点后拖动，或输入 X/Y 精确坐标；支持增删、排序，默认 0.5 格吸附，Alt 精细拖动。移动装置带动全部节点，序号为 I、II、III。旧 JSON 文本方式改由节点图统一管理。

区域选中后拖动四个角点调整，保持最小一格；按键提示按钮可隐藏/显示工具按钮快捷键。

温控板行为中选择「初始状态」：继承区域、初始冷或初始热。显式设置同时初始化所控区域，冰块和预览随之保持一致。

试玩自动记录。用「保存 / 显示路径」命名保存；编辑页的「试玩路径」可管理、读取文件和勾选多条路径同时显示。路径随项目保存，可单独导出 JSON；重试分段不连线，多个房间分别记录。

2.4.0：方块基础属性可开关碰撞，无碰撞显示虚线；AI 启动板只有一种，关闭碰撞时经过触发。冷热控制器选择温控区，范围覆盖到的冰块自动响应；重叠区热优先。冰块不再有区域选择或关联。冷态再生成仍会等待玩家/AI 离开，避免夹住角色。旧 JSON/ZIP 继续读取，具体兼容边界见 PROJECT_FORMAT。

## 框选与节点缩放（2.4.1）

点击顶部「框选」或按 M，拖框选中对象；选择工具也可从空白处开始拖框。Shift 左键追加，Shift 右键反选，点选和拖框均可；反选范围内已选项取消、未选项加入。普通拖框替换当前选择。拖动任一选中对象会整体移动，Delete 删除、Esc 清空；移动与删除各占一步撤销。框选支持地形、功能块、机关砖、出入口和区域。删除带线端口前会提示，最后一个入口不能删除。

新放置电磁炮的起点 0 在方块中心，其余节点以罗马数字排列；旧关卡保持旧节点坐标。画布节点标记、文字随画布缩放；右侧概览仍自动适配整条轨道。

## 2.4.2 编辑与试玩

属性页的「锁定位置」禁止拖动与缩放，不影响机关运行。选择已选方块开始拖动时保持选中；只有原地点击才切换重叠对象。新放置方块默认开启碰撞，可单独关闭；关闭碰撞仍保留触发范围。AI 距离条件与一次性/冷却规则继续生效。

退出试玩选择「保存路径并退出」「不保存并退出」或「继续试玩」。保存只消费未保存的本次采样，每条生命可单独勾选，名称为 1、2、3 等数字，同一命跨房时在各房各保留一条记录，之后再次保存不会加入之前保存过的采样。手动路径管理的保存也消费当前缓存；已有路径不自动拆改。

同一场试玩中，同一条命再次手动保存只追加尚未保存的新采样，不重复新建相同生命记录。退出时未勾选的生命不保存；旧有路径记录保持原样。
