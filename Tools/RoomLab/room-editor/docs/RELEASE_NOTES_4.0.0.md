# Room Lab v4.0.0

完整解压 Windows 程序包后打开 RoomLab.exe。本版在 3.1 统一三主题机关库的基础上，加入道具系统与巡查老师。

## 道具系统

- 咖啡：持有后清醒板变为无实体区域，可按进入方向上下左右加速；未持有时清醒板为普通实体砖。
- 计算器：持有后才能使用积分聚合板和求导展开板。
- 手机：持有后才能使用签到板。
- 冰红茶：持有后 token 才能为二段冲刺充能；付费冲刺库存上限为 1。
- 四种道具均可作为无碰撞方块放置，经过拾取进入试玩背包，并显示在试玩 HUD。

## 巡查老师

- 可在地图任意位置放置，默认在设定的平台左右范围之间往返巡逻。
- 可编辑平台左右边界和移动速度。
- 可绑定本房多个签到板，支持属性勾选、快捷绑定和右键/框选绑定。
- 全部绑定签到板激活后巡查老师消失。
- 同一老师第一次碰撞扣除一半 token，第二次碰撞直接死亡。
- 不同老师独立累计，连续碰到两名不同老师会扣除两次一半 token。

## 兼容性

- 项目格式仍为 v2。
- 3.1 项目可直接打开；清醒板旧版本会迁移到 1.2.0 实体默认。
- 页面布局、按钮位置和原有视觉风格保持兼容。
