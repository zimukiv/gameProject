## 导入房间

1. 打开目标项目，点右上角「导入房间」。
2. 选择此前「导出房间」得到的 ZIP；也可选完整项目 ZIP，再在窗口中选择其中一个房间。
3. 选择目标大关、房间，点「导入到大关」。导入完成后自动进入新房间。

导入是追加操作，不替换现有房间；重名自动增加「导入」后缀。房间、机关、温控区和轨道子节点重新分配 ID 并修复内部关联；素材冲突另存，内容与设置相同的可复用。导入可用 Ctrl+Z 撤销。

默认勾选「保留房间原美术」，该房间使用独立美术绑定；取消勾选则采用当前大关的美术，原实例外观覆盖仍保留。房间机关参数保留，移动和冲刺等项目级规则使用目标项目设置。与其他房间的接线需在接线板重新建立。

项目仍采用 v2 JSON。新增可选 room.artBindings 用于导入房间的独立美术，缺省时沿用大关。旧版本可读取房间参数，但旧绘制器可能使用大关美术；协作双方应使用 2.5.1。
