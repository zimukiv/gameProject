# Room Lab 2.5.3 · 桌面连接兼容修复

适用于同一密钥在网页可查看节点，但编辑器导入提示 HTTP 403 的情况。

1. 解压整个新程序包，运行其中 RoomLab.exe。
2. 打开云同步，把网页已验证能用的同一连接密钥粘贴导入。
3. 连接成功后再选择云端节点切换。只连接不会上传或覆盖关卡。
4. 若仍报错，点「复制诊断信息」，将复制的报告反馈。报告不含密钥或关卡内容。

程序改用 Chromium 的系统网络通道，保留服务器证书验证和禁止携带密钥跳转的约束。读取握手可验证公开网站的工作区认证；不改变网站访问权限，不重放失败的写请求。旧连接密钥继续兼容，2.5.2 的视角设置、房间导入、云端节点图和路径功能保留。

本机已对照公开网站的带/不带服务凭据访问；原 curl 在本机均正常，因此这不足以证明队友端具体是凭据、代理、网络过滤或系统环境中的哪一项。新版提供对应的诊断证据，最终仍需队友设备复验。
