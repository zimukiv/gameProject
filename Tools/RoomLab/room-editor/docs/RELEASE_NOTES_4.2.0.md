# Room Lab v4.2.0

完整解压 Windows 程序包后打开 `RoomLab.exe`。4.2 在 4.1.1 的镜像是房间编辑、机关砖节点和接线板排布基础上，新增 AI 终止装置、开发试玩和入口反向返回开关。

## 新增功能

- 新增三主题通用流程装置「提交作业」。AI 正在追逐时踩踏触发，AI 立即消失并停止跨房追击，同时一次性增加 50000 分。AI 未启动时不会消耗，装置不能重复刷分。
- 新增开发者试玩模式。从房间编辑器点击「试玩此房」或「从此入口试玩」会自动携带咖啡、计算器、手机和冰红茶；从大关总览点击「从首房试玩」仍为空背包，需要在关卡中自行寻找道具。试玩 HUD 会显示开发者模式。
- 入口「关联」属性新增「允许从此入口返回连接的出口」，默认允许。关闭后正向进入保持正常，但离开并再次触碰该入口不会反向返回来源出口。旧项目缺失该字段时按允许解释，不改写旧文件。
- 新增提交作业内置 SVG、三主题共享素材绑定和编辑器分类；插件接口增加 `canTrigger`、`stopAI()` 和 `addScore()`。

## 兼容性

- 项目格式仍为 v2，4.1.1、4.1 和 4.0 项目可直接打开。
- 新增入口字段 `allowReturn` 为可选布尔值；旧入口未填写时视为 true。
- 房间、接线、素材、云同步和剪贴板结构保持兼容。

## 验证

- 核心测试覆盖提交作业 AI 终止与计分、开发者模式道具差异、入口返回开关及旧数据兼容。
- 浏览器与实际 Windows EXE 验证装置放置、AI 停止、50000 分、开发试玩全道具和入口属性保存。
