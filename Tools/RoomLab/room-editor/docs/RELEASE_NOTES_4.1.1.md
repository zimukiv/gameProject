# Room Lab v4.1.1

完整解压 Windows 程序包后打开 `RoomLab.exe`。本版修复冰块融化后仍有隐形碰撞的问题，修复物理/水课大关机关砖无法添加移动节点的问题，保存接线板房间排布，新增整房左右/上下镜像，并保留 4.1.0 的入口反向返回与跨大关整房复制粘贴功能。

## 新增功能

- 房间属性底部新增「↔ 左右镜像」和「↕ 上下镜像」。
- 镜像会同步翻转地形、入口出口、机关砖、功能对象、温控区域、运动/轨道节点、巡查范围、原生扩展平台/巡逻/标记和试玩轨迹。
- 左右镜像会交换左右方向与入口朝向；上下镜像会交换上下方向。喷气速度、旋转角度和轨道出射角按镜像轴同步变换。
- 所有对象和端口 ID、房间尺寸及跨房接线保持不变。每次镜像作为一次修改进入撤销历史，连续镜像两次可恢复原布局。

## 修复内容

- 冰块被热区融化或累计站立融化后，运行时碰撞会与画面状态同步移除。
- 冰块回到冷态并重新生成后，碰撞会正常恢复。
- 修复原因：冰块插件缺少 `dynamicSolidity: true`，运行时未调用其 `isSolid()` 状态判断。
- 机关砖的「节点图」、画布添加节点、右键添加节点及多选编组不再仅限高数大关；物理、高数、水课现在共享同一套机关砖路径编辑能力。
- 接线板中的房间坐标继续写入项目 v2 的 `room.graph`，并随本地草稿、JSON/ZIP 保存和云同步保留。重开编辑器时只补齐缺失坐标，不再因卡片重叠或间距较近而自动覆盖用户排布；需要时可手动点击「整理排布」。

## 兼容性

- 项目格式仍为 v2，4.1 和 4.0 项目可直接打开，无额外迁移。
- 房间、接线、素材、云同步和剪贴板数据结构不变。
- Windows x64 便携包仍需完整解压，保留同目录运行时文件。
