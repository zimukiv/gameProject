# Room Lab 2.5.0

## 云同步窗口

按「连接密钥 → 云端节点图预览与切换 → 本机工作树与保存」分区。导入或打开窗口时读取云端节点图，点击节点右侧显示说明、时间、设备、文件数、原始来源及展示关系；滚轮缩放、空白处拖动平移。

- 「切换到此版本」先提示保存当前修改，再下载为本机工作树；同一版本重复读取复用已有干净节点。有修改的旧草稿单独保留。
- 选中节点后，按「上传当前草稿到此节点下方」或「保存同步为新分支」，建立该节点的子版本；原节点不会覆盖。
- 「取消选择」后，保存同步仍从上次读取的版本建立子节点。临时选中上传目标不改变上次读取来源。关闭并重开同步窗口清空临时选择。
- 编辑器内的云端图只预览、切换和选上传目标；改关系和删除在「浏览器中管理关系 / 删除节点」里操作。本机工作树管理仍保留，作用于本机记录。

## 浏览器节点管理

在原云端网址导入相同密钥，选中节点后可在右侧选择父节点并「应用关联」。也可打开「拖动改关联」，将节点拖到目标父节点；移为根节点用右侧下拉框。

「删除此节点」需要确认，节点进入回收站，子节点上移一级。回收站恢复为根节点，可再指定父节点。删除不销毁历史文件；本地已有草稿不被删除。整理关系仅修改展示元数据，保留不可变版本 ID、校验信息及原始保存来源。

禁止自关联和关联到后代；其他端保存或整理关系后，过期操作提示刷新，不覆盖对方调整。编辑器选中节点若被删除，上传会报错并保留本机草稿。两端建议都更新至 2.5.0。

## 单房间导出

编辑房间时右上角「导出房间」可导出当前房间；接线板选中房间后，右上角及右侧详情均有导出入口。

导出为可直接用「导入项目包」打开的 ZIP，含所选房间、大关规则、机关参数、内部 ID、试玩路径及所需素材。跨房间接线不参与单房间运行，原接线作为来源说明保留。独立包使用新项目 ID，避免误同步覆盖原完整项目；原项目及房间内容不被修改。

项目数据格式保持 v2，不批量迁移或重写现有文件。旧版不显示新的云端关系整理信息；温控、碰撞和自定义参数沿用原兼容处理。
