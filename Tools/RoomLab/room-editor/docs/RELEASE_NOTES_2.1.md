# Room Lab 2.1.0 · 2026-10-07

## 使用

解压完整 Windows x64 包，在解压目录运行 RoomLab.exe。开发环境不必安装；源码 ZIP 供程序同学维护修改。打开已有 v2 项目或含素材的项目包即可继续编辑，分类缺失时从现有绑定推断。

## 更新内容

- 房间切换移到顶部横栏；画布随窗口放大，属性栏可收起，按键说明集成到按钮。
- 分组图标栏一键选择并连续放块，显示当前大关素材缩略图；窄窗口下可横向滚动。
- 素材库按大类 → 子类 → 素材展开；目录导入自动分类，可在资料中改类。实例外观与大关美术绑定只展示对应类别和大关范围内的素材。
- 接线板滚轮锚点缩放、中键平移、查看全部及 100% 复位。
- 缩略图每格保持同一预览尺度，房间卡片按实际列数与行数调整宽高。标题加大、备注多行显示。
- 入口、出口位置对应房间实际坐标，以高对比实心点和名称标明；连线采用平缓曲线。

## 验证与边界

发行前运行核心检查、布局与接线真实鼠标检查、素材 ZIP 往返、三房真实键盘通关，并对实际打包 exe 验证原生文件读写、中文路径和试玩。最终结果记录在 release/latest-release.json。

内容仍限于物理大关三房示例。AI 为本地占位追逐，未接入策划中的 AI 技能；数学、水关等内容未制作。整体源码结构与编辑器功能说明见 README 和 docs。
