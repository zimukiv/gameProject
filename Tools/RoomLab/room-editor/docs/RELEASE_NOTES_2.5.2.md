# Room Lab 2.5.2

包含 2.5.0 的云端节点图、浏览器关系整理与删除恢复，以及 2.5.1 的同步窗口精简和房间导入。

## 每房间的试玩视角

1. 进入房间，点上方「房间设置」。
2. 在右侧「试玩视角」选择「完整房间」或「自适应跟随」。
3. 跟随模式下设置默认视野宽、高，单位为格，点「应用房间设置」后试玩。

跟随模式至少显示设定宽高范围，再根据窗口比例适配；额外的方向可能显示更多内容，不拉伸画面。大房间跟随玩家，小房间完整显示。接近房间边界时停止平移，重试后立即回到入口视角；切换房间采用目标房间自己的配置。可用小数视野，范围 1–256 格。

试玩标题旁显示当前实际视野大小。设置不改变物理或编辑器画布缩放，不改写已有试玩路径。旧房间未配置时继续完整房间显示。配置随项目、单房间 ZIP、复制、导入与云端保存一起保留。

## 房间导入

右上角「导入房间」→ 选择房间 ZIP 或完整项目 ZIP → 选择目标大关和房间 →「导入到大关」。追加保留现有房间，重名自动改名，素材冲突另存，房间内引用自动调整，可 Ctrl+Z 撤销。详见 2.5.1 使用说明。

## 同步窗口

只保留密钥、云端节点预览与切换、新建云端分支三个部分。本地树管理及下方历史、文件关联和恢复位置入口已移除。选中云端节点即以该节点作为新分支父节点；取消选择则使用上次读取的版本。
