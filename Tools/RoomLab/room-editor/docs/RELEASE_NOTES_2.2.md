# Room Lab 2.2.0 · 2026-10-08

- 电磁炮、喷气、温控与 AI 启动板等贴图按存储格子左上角绘制，去除旧版的上移偏移。选择命中与贴图使用同一格范围。
- 擦除支持地形、功能块、收集物和机关砖；移除机关时清理关联，整次拖动可一步撤销。房间入口/出口与温控区域仍用选中后删除管理，避免断开接线或区域关联。
- 功能块支持长按拖动连放，补全快速拖动跨过的格子，不重复添加同类对象；入口/出口、温控区域和传送接口保持单点放置或区域绘制。
- AI 实心启动板为完整实体格，站到顶面触发；空心启动板无碰撞，经过其区域触发。旧 common.aiStart ID 保留，旧项目可直接打开。
- 每个新电磁炮实例独立保存轨道数组，编辑其中一个不会改到其他实例。
- 试玩画布像编辑画布一样适配窗口，整房视角保持比例；状态栏可展开/收起，按键说明收进按钮。修复进入试玩时画布聚焦导致页面滚动、顶部栏被挤出视野的问题。

数据格式仍为 v2。AI 仍是本地占位追逐，没有在线模型或技能配置。Windows 完整包解压后运行 RoomLab.exe；源代码与测试随源码包提供。
