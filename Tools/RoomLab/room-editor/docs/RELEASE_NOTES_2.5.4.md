# Room Lab 2.5.4

## 云端节点与批量房间导入

编辑器的云端节点图改为显示项目名称、房间总数。选中节点后，右侧按大关列出房间名称、备注、尺寸、机关与出入口数量。保存说明、设备和版本 ID 收进「保存说明与版本信息」。旧版本节点可读取名称与房间详情，无需重存。

勾选若干房间 →「导入所选房间」→ 选择目标大关。也可使用顶部「导入房间」选择完整项目 ZIP，再勾选多个房间。

- 同名默认「独立导入」，自动增加后缀；可按房间分别选择覆盖及具体覆盖目标。
- 覆盖前显示房间清单及受影响连线数，确认后才一次性应用。覆盖会替换房间地形、机关、设置与原保存路径，可整体撤销。
- 覆盖保留目标房间 ID、接线板位置和匹配的出入口。无法匹配的端口连线会清理；本次所选来源房间之间的接线会保留，冲突出口以导入连线为准。
- 素材冲突另存，相同内容与设置的素材复用。使用目标项目的全局移动、冲刺规则，默认保留房间美术和试玩视角。
- 只导入房间不会切换整个云端版本，也不会改变上次读取的同步来源；未导入的房间保留。

## 顶部房间拖动排序

在房间编辑页面，按住顶部房间标签左右拖动，插入标记表示目标位置。移到标签栏边缘可自动横向滚动。一次拖动对应一次撤销，房间 ID、内部数据、接线与当前编辑缩放保留。最左房间是「从首房试玩」的起点。

即时协作中，单端排序与另一端的内容修改可以合并；双方给出不同排序时按冲突处理，不静默丢弃本机顺序。

## 路径回放与自命名

打开「试玩路径」，每条已保存路径旁有「回放」，也可「回放勾选路径」比较多条。支持播放 / 暂停、拖动进度、0.25–4 倍速、循环、跟随角色和多路径勾选。使用录制时间插值位置，死亡或跨房分段不连成移动轨迹。旧无时间记录采用均匀采样时间。

回放只展示轨迹角色，不重演机关或 AI；不会修改关卡、旧路径或生成新的录制。试玩中打开回放会暂停实际游戏，关闭后恢复。

**每次点击「回到编辑」后的「是否保存这次试玩路径？」窗口**有「全选 / 反选」，只选择本次要保存的各条命。每条命旁可输入名称，留空使用生命编号；默认名称仍是数字。路径管理的保存区域也提供相同选择与命名。

已保存路径可直接输入名称并「改名」，只更改名称，保留路径 ID 和采样点。名称最多 80 字，同名路径独立存在，不按名称合并或覆盖。

项目格式仍为 v2；房间 ID、素材路径与历史数据保持兼容。新版本保存时附带少量节点名称摘要，旧节点通过只读项目元数据展示，无需数据库迁移。
