# Room Lab v3.1.0

完整解压 Windows 程序包后打开 RoomLab.exe。本版保留物理、高数、水课三个大关的现有卡片、配色、房间结构和起始内容，但取消主题对机关工具的限制。

- 三个大关的所有房间均可使用喷气、冰块、温控板、电磁炮、积分聚合板、求导展开板、签到板和清醒加速板。
- 机关砖与温控区域在三个大关中都可直接放置。
- 三套内置机关素材在各大关均可选择并默认绑定；用户自定义素材仍按所属大关隔离。
- 打开旧项目时自动补齐缺失的内置素材和绑定，不覆盖已有绑定、ID、房间、接线或试玩路径。
- 项目格式仍为 v2，云同步协议和现有 Unity 数据格式未改变。

页面结构、按钮位置和视觉样式保持与 3.0.0 一致，改动集中在可用机关、默认素材和功能块定义范围。
