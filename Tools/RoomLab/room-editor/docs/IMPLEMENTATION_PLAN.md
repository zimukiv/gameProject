# 第一大关版本执行合同

本次由 Codex 直接实现，不使用 DSH。原 demo 目录和已有项目数据保持原状，新工程为 room-editor。

1. 项目 v2 数据、大关/房间、可变尺寸、入口/出口/连线、旧格式迁移及规则测试。
2. 项目→大关→接线板→房间的分层界面，房间命名/备注、撤销和画布编辑，真实鼠标验收。
3. 素材库、大关状态素材绑定、实例覆盖、功能块注册及参数定义，保存与项目包往返验收。
4. 第一大关机制、免费首冲与房间检查点，真实键盘通关及状态回退验收。
5. 原生项目文件操作、Windows exe、完整源码与必要文档，打包后应用验收。

依次实施，通过当前阶段检查后进入下一阶段。仅制作一个大关内容，其他大关保留数据扩展能力。

确认规则：每次实际落地恢复免费首冲，免费首冲计入三段上限；AI 距離量到机关；AI 技能不配置，仅保存 AI ID。第一版房间默认 30×17，每格 32 世界像素，房间宽高可改。

全项目数据使用相对素材路径及稳定 ID。物理素材、模块默认参数和实例参数分离。编辑器项目保存与游戏检查点分离。
