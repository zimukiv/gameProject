# 云同步与工作树 · 2.4.0

关卡文件继续使用 v2。云端连接、工作树、草稿和分支来源放在独立存储中，不加入关卡 JSON。旧版 JSON / ZIP 可直接导入；导出时保留素材、稳定 ID、房间、接线、节点和试玩路径。旧原件不覆盖，正式保存仍保留 JSON 备份。

## 两台电脑连接

1. 这台电脑已配置私有 Sites 中转。顶部「保存同步」→「连接设置」→「复制连接密钥」。私下发给队友；程序包、源码和项目包均不含密钥。
2. 队友打开同版程序，粘贴导入密钥，点「查看云端分支」→「下载为工作树」→「切换」。第一次使用，先由一端保存同步一版，再让双方读取该版本。打开不同来源版本不会进入同一即时协作会话。
3. 顶部管理窗口切换「手动保存同步」或「即时协作」。两端都选即时模式并打开相同来源版本，在线状态才显示双方协作。

## 即时协作

约每秒请求一次协作状态，实际显示延迟受网络和素材大小影响。双方在线时，房间内容、机关参数、素材和接线等草稿修改会相互显示；首次素材要先上传。拖动中的修改在松开后同步。试玩继续交换编辑草稿；试玩引擎保持进入时的快照，退出试玩后显示新的关卡修改。断开一端后最多约 8 秒检测离线，草稿保留在本机，下一次双方在线后继续。

即时修改**不会自动建立版本或工作树**。本机 `drafts` 中保存最新恢复草稿；服务器暂存协作清单，与版本表分开，24 小时未更新的协作清单不再用于加入会话。当前没有定期清理历史素材分块，因此「临时」不代表 24 小时后物理删除所有字节。

不同房间、不同对象或不同字段的修改可合并。双方修改同一字段，或一方删除另一方正在编辑的对象时，保留本机与对端恢复草稿，暂停发布冲突字段；打开管理窗口，先手动保存本机分支，再选「采用本机草稿继续」或「采用对端草稿」。不会静默覆盖冲突。接收对端修改时清除旧的整项目撤销栈，防止一次撤销把对端修改回滚。

## 手动保存与分支来源

日常修改只更新恢复草稿。点「保存同步为新分支」才创建完整版本并上传。顶部「保存项目」在文件保存成功后，也建立一个手动版本并尝试上传；上传失败仍保留本机版本和正式项目文件。

每次保存从**上次读取的云端版本**派生子分支。连续保存但没有重新读取时，会形成同一来源下的多个子分支，原分支保持原样。版本列表显示来源版本。重新下载并切换某个云端版本后，后续保存才以它为新来源。

工作树可以命名并独立保留草稿。切换或读取其他版本前，提示是否保存正式项目文件；恢复版本先载入草稿，下一次手动保存才生成新版本。不同项目 ID 自动隔离工作树。

「新建大关」往当前项目追加大关，保留现有房间和项目 ID。打开、导入、新建大关、读取其他版本或退出时，有未保存修改则显示「保存后继续 / 不保存并继续 / 取消」。取消文件选择或保存失败时不执行后续操作。

## 位置、权限和限制

服务：[Room Lab 云同步](https://room-lab-cloud-vgbvhh.liuvgbvhh.chatgpt.site)。D1 保存版本、分支和临时协作清单；R2 保存经 SHA-256 校验的文件分块。Site 保持所有者私有，通过同一连接密钥供桌面调用；浏览器查看页面另需所有者登录。

本机：`%APPDATA%\RoomLabSync`。`connection.vault` 使用 Windows 加密，不能当作跨电脑密钥文件；请在原电脑复制连接密钥。`repository.json` 和 `.bak` 是版本索引，`snapshots` 是手动完整版本，`drafts` 是恢复草稿。备份整个目录前关闭程序。建议定期另行导出项目 ZIP。

密钥可访问整个工作区，请只交给可信队友；本版没有队友级权限、单人撤销或端到端加密。Site 所有者撤销服务授权后，两端需更新密钥。请求只发送到密钥内的 HTTPS Sites 地址，拒绝重定向；Windows 使用系统自带 curl TLS 组件，密钥仅通过进程 stdin 传递，不进入命令行参数。

单项目内容 128 MiB、单文件 32 MiB、最多 1024 文件和 512 个 4 MiB 分块；素材导入仍保持原有 20 MiB 限制。当前不自动删除本机或云端版本；界面列出最近 200 个本机版本、100 个云端版本及 200 个分支。即时协作需要双方打开程序，关闭程序后不后台同步。

## 复制连接密钥按钮不可用

输入框里的 `rlsync1.…` 是占位提示，不是已经保存的密钥。只有正式程序成功读取加密连接后，复制按钮才可用。2026-10-25 修复了维护者初始化工具使用测试配置的加密密钥、导致正式程序读不到连接的问题；现有电脑保留原工作区密钥，备份旧密文后按正式配置重新加密，不改项目和版本记录。修复后关闭再打开云同步面板即可刷新，无需重下 Windows 包。

维护者初始化必须使用正式 userData 的 Local State 加密信息，不能用随机测试 profile 加密后写入全局连接文件。工具在编辑器运行时只复制 Local State 到隔离环境做加密，不修改运行中的正式配置；已有连接必须经过正式配置解密和云端认证，才可报告配置成功。测试：`node tests/cloud-bootstrap-smoke.cjs`。

## 2.4.1 连接排查与工作树管理

在「云同步与工作树」点击「检查连接」，只验证密钥、Windows 配置读取与云端认证，不上传关卡。尚未导入、配置读取失败、已导入待验证、认证成功是不同状态。导入失败后顶部显示错误，复制按钮保持禁用；从主电脑私下复制完整密钥到队友电脑导入。程序包本身不携带密钥。

树图中拖动左侧 ⋮⋮ 到目标节点，确认后改变本机关联；拖到「移为根节点」解除父关联。也可点「管理」使用下拉框。实际版本来源保留在下方「手动保存的版本来源图」，后续手动保存仍从上次读取的云端版本产生分支。此版关联整理不跨端同步。

管理可改名、选择关联本地 JSON、解除关联及打开文件夹。节点显示项目包含的大关名称与房间数、文件路径及缺失状态。同名创建/改名需确认，同分支名不能重复创建；同一云端版本重复下载直接提示并复用。多个工作树关联一个文件时显示提示，覆盖文件前再次确认，并检查文件是否被其他程序改过。

删除节点放入本机回收站，当前节点须先切换；子节点提升一级，草稿、历史快照和云端分支保留。回收站可恢复节点。文件关联只记录位置，不自动替换编辑草稿或回写文件；读取其他版本之后要通过保存项目选择文件位置。

本次本机生产配置的隔离只读检查可解密并通过正式云端认证，但不能替代队友端的实际连接验收。错误配置的重新导入现可修复；不要发送密钥截图或在公开群粘贴密钥。

## 网站节点图

云端网站粘贴同一连接密钥后，按不可变版本 parent 显示节点图。点击节点高亮并读取其关卡说明、房间尺寸、素材清单；可下载单个文件或完整项目包。缺少的更早来源可点击载入。搜索按版本说明/分支/版本号匹配，滚轮缩放、空白处拖动平移。

桌面「云端节点图 / 文件管理」只在网址片段传当前云端版本，不把密钥放进网址。需要在网页粘贴密钥，断开后清空页面会话；网页不保存密钥到 localStorage。保留 Sites 当前访问范围，工作区 API 继续要求 43 位工作区密钥。网页是读取/下载管理，不自动删除历史或新增分支。
