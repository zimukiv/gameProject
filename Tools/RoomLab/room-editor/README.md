# Room Lab 2.5.5 · 第一大关编辑器

源码与程序包发布至 [GitHub](https://github.com/zimukiv/gameProject/tree/main/Tools/RoomLab)。每次修改前先执行 `node scripts/check-upstream.cjs` 核对远端最新源码，详见 [协作与发布规则](docs/GITHUB_WORKFLOW.md)。

2.5.5 合入朋友版的存档点、喷气方向显示与可选电磁侧面触发；喷气碰撞仍可独立切换。朋友版未标记存档在首次读取时保留其特殊机关行为，不改变普通旧关卡。详见 [2.5.5 使用说明](docs/RELEASE_NOTES_2.5.5.md)。

当前版新增云端房间详情与多选导入、同名覆盖 / 独立、顶部房间拖动排序、路径回放与自命名。**退出试玩时的路径保存窗口**提供全选 / 反选。详见 [2.5.4 使用说明](docs/RELEASE_NOTES_2.5.4.md)。

按大关和房间制作关卡，摆放踩踏机关、导入素材、连接入口出口，并立即试玩。此版只提供物理大关内容，内置三个连通房间：喷气起跳 → 温控与累计融冰 → 电磁加速提交。

## 使用发布版

解压整个 Windows 压缩包，打开其中的 **RoomLab.exe**。同目录 DLL、resources 等必须一起保留。无需安装 Node 或游戏引擎。首开即有完整物理示例；也可打开 `examples/physics/project.json` 或导入 `examples/physics-project.zip`。

从大关卡片进入接线板，双击房间缩略图编辑。房间内右侧属性逐层展开，尺寸可编辑；入口出口可命名并拖线连接。顶部「素材库」管理图片，「功能块」修改以后新放置对象的默认参数。大关「美术绑定」设置类型与状态的素材；对象「外观」可覆盖。

2.1 版：顶部横栏切换房间，图标选择栏直接放块，属性栏可收起扩大画布；素材库按大类、子类、图片逐层浏览，应用时只显示匹配类别；接线板支持滚轮缩放和中键平移，卡片与缩略图按房间实际尺寸调整，接口用实心点标在实际位置。详见 [2.1 更新说明](docs/RELEASE_NOTES_2.1.md)。

2.2 版修复踏板贴图与选择位置不一致，擦除工具支持功能块；功能块可长按拖动连续放置。AI 启动板分实心（可站立、踩触发）和空心（无碰撞、经过触发）。试玩画布自适应窗口，默认收起状态栏；详见 [2.2 更新说明](docs/RELEASE_NOTES_2.2.md)。

2.3.1 新增轨道子节点管理（拖动、精确坐标、罗马数字、节点图）、可隐藏按键提示、区域四角缩放、试玩路径保存读取与多路径勾选叠加，以及温控板初始冷/热设置。详见 [2.3.1 更新说明](docs/RELEASE_NOTES_2.3.1.md)。

试玩使用 A/D 或左右移动，W/↑ 与 S/↓ 决定冲刺方向，空格跳跃，Shift 冲刺，R 重试，Esc 暂停。每次实际落地获得一次免费冲刺，计入该轮最多三次；其他冲刺消耗金币充出的库存。

桌面版「保存项目」保存 JSON 和同目录 assets，覆盖 JSON 前留备份。完整传给队友请「导出项目包」；不要只发 JSON。浏览器草稿只存当前浏览器，正式保留请保存文件或导出 ZIP。

2.4.0 增加私有云同步、即时草稿协作与手动子分支保存；两端使用同一连接密钥。新建大关保留已有内容，离开未保存修改前提示保存。方块可切换碰撞，AI 启动板统一为一种；温控区按空间范围影响冰块，无需冰块绑定。详见 [云同步与工作树](docs/CLOUD_SYNC.md)。

2.4.1 增加工作树关系图、拖动调整本机关联、改名、删除回收站、本地项目文件关联与重复/覆盖提示，修复连接失败的状态及复制按钮。编辑后保留缩放和平移，房间最大 256 × 256 格。详见 [2.4.1 更新说明](docs/RELEASE_NOTES_2.4.1.md)。

2.4.2：云端网站提供版本节点图、详情和项目/素材下载；桌面增加网站入口。触发与碰撞分离，新增位置锁定并修复区域重叠选择；新放置方块默认有碰撞。退出试玩询问保存，未保存片段与重试分开记录。详见 [2.4.2 更新说明](docs/RELEASE_NOTES_2.4.2.md)。

## 开发与重建

2.5.2：房间内点「房间设置」，可选择试玩整房视角或自适应跟随，并保存默认视野宽高（格）。窗口变动自动适配，旧房间沿用整房显示。详见 [当前版本使用说明](docs/RELEASE_NOTES_2.5.2.md)。

2.5.1：顶部「导入房间」将房间 ZIP 追加到目标大关，支持从完整项目包选择一个房间，自动处理重名、素材和内部关联。同步界面已移除本地树管理，第三部分改为「新建云端分支」。详见 [2.5.1 使用说明](docs/RELEASE_NOTES_2.5.1.md)。

2.5.0：同步窗口嵌入云端节点图，支持查看详情、切换及选择上传父节点；浏览器可整理关系、删除与恢复。右上角及接线板房间详情支持单房间完整 ZIP 导出。详见 [2.5.0 更新说明](docs/RELEASE_NOTES_2.5.0.md)。

Windows x64，Node.js 22.12+（建议 24 LTS），pnpm 11+。在本目录执行：

```text
pnpm install --frozen-lockfile
pnpm setup
pnpm start
```

`setup` 下载 Electron 平台程序，首次需网络；启动自动构建界面。`pnpm build` 单独生成 build。`pnpm test` 运行核心测试；界面和桌面测试见 [测试说明](docs/TESTING.md)。`pnpm package` 生成便携程序、Windows ZIP、源码 ZIP 与校验信息，输出 release；再次打包建立新目录，保留旧发布。`pnpm examples` 重建独立示例，`pnpm docs` 从插件注册表生成参数目录。

源码使用 UTF-8、两空格缩进和 LF 换行，`pnpm format` 统一格式，`pnpm format:check` 校验。

## 当前边界

这是第一大关编辑器及玩法验证 demo。素材为自制示意图；三个房间用于验证机关和流程，比赛关卡仍需人工调难度。AI 为本地确定性轨迹追逐占位，只登记 AI ID，没有实现策划中的 AI 技能或调用在线模型。数学、水关、签到与教师内容未制作。方块模块在源码中注册并重建，暂不支持从 UI 安装任意代码插件。大关结束出口是未连线的出口，编辑时须特别确认；尚无引擎专用导出器。
