# Room Lab 编辑器与云同步服务

此处是 Room Lab 2.5.5 源码；与仓库根目录 Unity 游戏及 PhysicsLevelEditor r5 分别维护。

- `room-editor/`：编辑器、试玩、测试、Windows 打包与维护文档。
- `room-cloud/`：可选云同步网站、存储接口和数据库迁移。
- [Windows 程序与源码包](https://github.com/zimukiv/gameProject/releases/tag/roomlab-editor-v2.5.5)

完整解压程序包后打开 RoomLab.exe。源码开发先读 room-editor/AGENTS.md，每次修改前核对 GitHub main 最新版本。
