## 拉取与启动

已有仓库先保存自己的修改，然后执行：

```sh
git fetch origin codex/roomlab-ddl13-v3-handoff-2026-10-26
git switch --track origin/codex/roomlab-ddl13-v3-handoff-2026-10-26
```

首次获取也可以直接执行：

```sh
git clone --branch codex/roomlab-ddl13-v3-handoff-2026-10-26 https://github.com/zimukiv/gameProject.git
cd gameProject
```

仓库根目录直接包含 `Assets`、`Packages`、`ProjectSettings`，无需再进入 `UnityProject`。Windows PowerShell 在该目录执行：

```powershell
& .\Tools\RoomLabExactHost\setup-runtime.ps1
```

脚本下载 Electron Windows x64 44.5.1，验证固定 SHA-256，准备 `.roomlab-runtime` 并复制版本化的玩法源码/素材，无需 `npm install`。已有完整试玩目录时可用 `-ExistingRuntime '解压目录\RoomLabRuntime'` 复用运行器；脚本仍会覆盖为本分支源码。运行脚本须允许团队 PowerShell 脚本执行和首次下载。

Unity Hub 添加仓库根目录，使用 **Unity 6000.6.4f1** 和 Windows Build Support。打开 **`Assets/RoomLabExactConnected/RoomLabExact.unity`** 后 Play。编辑器使用仓库内 `.roomlab-runtime`，不依赖 A 的绝对路径。

## 当前架构与修改入口

实际玩法是 RoomLab 2.5.2 的 JS 核心，隐藏 Electron 绘制后通过本机 TCP 将状态和 PNG 传给 Unity；Unity 负责输入、菜单和显示。旧 `Assets/Scenes/Level1/2/3`、PlayerController、EnemyAI 和原三关生成工具是历史原型。

| 路径 | 职责 |
| --- | --- |
| `Tools/RoomLabRuntimeApp/project.json` | 合并本地规则后的 DDL1.3，11 房间/10 连线 |
| `Tools/RoomLabRuntimeApp/src/runtime/engine.cjs` | 移动、冲刺、AI、拾取、复活、存档和开发者状态 |
| `Tools/RoomLabRuntimeApp/src/runtime/input-steps.cjs` | 按顺序消费输入采样，防止丢失或重复冲刺事件 |
| `Tools/RoomLabRuntimeApp/src/runtime/developer-map.cjs` | 当前房间全图和全关总览 |
| `Tools/RoomLabRuntimeApp/src/project/spikes.cjs` | 四向半圆外观和危险范围共享几何 |
| `Tools/RoomLabRuntimeApp/src/project/performance.cjs` | 移动加速等默认参数 |
| `Tools/RoomLabRuntimeApp/src/plugins/common.cjs` | 存档点等通用插件 |
| `Tools/RoomLabRuntimeApp/src/plugins/physics/ice.cjs` | 冰块融化、再生和切冷同步 |
| `Tools/RoomLabRuntimeApp/src/editor/draw.cjs` | 画面、半圆尖刺和存档激活样式 |
| `Tools/RoomLabRuntimeApp/main.cjs`、`renderer.cjs` | 运行器及 TCP 协议接入 |
| `Assets/Scripts/RoomLabExact/RoomLabExactPlayer.cs` | Unity 输入采样、TCP、画面、暂停/键位/开发者菜单 |
| `Assets/Scripts/RoomLabExact/RoomLabKeyBindings.cs` | 7 项操作的映射、冲突检查和 PlayerPrefs 保存 |
| `Assets/Scripts/Core/GameInput.cs` | 当前改键使用 Exact 物理键读取；旧别名方法供历史原型 |
| `Assets/Editor/RoomLabImport/RoomLabExactBuild.cs` | 连线版构建和构建前键位检查 |
| `Validation/BUGFIX_LOG.md` | 用户要求引用的原错误代码、原因、修复及验证 |

**后续修改 `Tools/RoomLabRuntimeApp`，再运行 `setup-runtime.ps1` 同步。** 不要只改忽略目录 `.roomlab-runtime` 或已导出包；它们不会随 Git 交接。`Tools/RoomLabExactHost` 中的旧 main/renderer 模板仅供历史参考。`upstream-source-hashes.json` 是上游原版基线，不代表定制后当前源码的哈希。

协议要点：Unity 发送 `samples: [{dt,input}]` 保留逐帧事件；开发者选项为 `{enabled,lockHealth,flight}`；地图参数为 `mapView: room|course`、`previewRoom`、`mapZoom`、`mapPanX/Y`。Frame 的 `mapRooms` 坐标属于画布，Unity 显示时 y 加 110。暂停/预览/复活清理输入事件，不能用一个 bool 合并多次按键。

## 已实现并应保留的规则

| 功能 | 当前行为 |
| --- | --- |
| 冲刺方向/资源 | 仅左右；无方向键时沿朝向。免费冲刺落地恢复，无累计次数限制。付费库存上限 3，每次落地前最多用一次付费冲刺，因此空中最多免费+付费两次；落地不补库存，跨房保留本轮付费使用标记。 |
| 水平微调 | 普通移动约 0.1 秒从零加速至 220px/s，持续按键匀速；松键停止，反向重新起步，冰面/冲刺/横向弹射保留各自分支。 |
| 复活 | 死亡或 R 重试后静默冻结 0.5 秒，无准备界面；玩家、AI、机关和计时等待，丢弃缓冲期间的跳跃/冲刺事件。普通开局/跨房不等待。 |
| 导轨 Token | 导轨滑行和冲刺可正常拾取；已验证 AI追逐1 实际导轨的两枚 Token。 |
| 半圆尖刺 | 1 格外观半径 14px、危险半径 11px；底边朝支撑墙面，支持四方向，悬空沿组排列；不作整格墙体阻挡。当前 214 个尖刺保留本地朝向。 |
| 冷热/冰块 | 从热切冷同次调用立即结冰；持续冷态踩踏融化后的原再生间隔保留，重叠热区仍有效。“冰 跑酷”原 5 秒的 25 块改为累计站立 2 秒，另一个 1 秒块保留。 |
| 暂停与改键 | Esc 菜单可退出游戏、修改键位、进入开发者功能。7 项操作各 3 个槽位，冲突/保留 Esc/至少一键校验，自动保存及恢复默认。 |
| 开发者锁血 | 默认关闭、仅本次运行。免疫尖刺和 AI 死亡/偷取；掉落回当前存档点或房间入口，不重置资源/机关/死亡次数；R 仍可重试。 |
| 开发者飞行 | 使用现有左右/跳跃/下蹲映射移动，松键悬停、可穿墙；不拾取、不触发机关/存档/出口。关闭时选择安全位置恢复正常物理。 |
| 全局地图 | 开发者菜单查看当前/其他房间全图、11 房间与 10 连线总览；全图滚轮缩放、左键拖动，点击缩略图预览其他房间。预览期间游戏暂停，Esc 返回菜单。 |
| 存档点 | DDL1.3 新增 7 个（AI追逐1 2 个、XX 5 个）。实际接触保存安全位置、资源、积分、收集和机关快照；死亡/R 恢复最近点，AI 相对该位置重建，仍有 0.5 秒缓冲。同一旗子持续接触不重复覆盖。 |

存档仅在本次运行的当前房间有效，退出不续关；切房建立新房间入口快照。键位通过本机 `PlayerPrefs` 的 `RoomLab.KeyboardBindings.v1` 保存，不随 ZIP 或 Git 传给 B。A 本机测试时曾将冲刺主键改成 J，默认新用户仍是左右 Shift；已有同产品偏好的机器若按键不同，先看 HUD 或在菜单恢复默认。开发者选项不写磁盘。

默认操作：A/D 或 ←/→ 移动，空格/W/↑ 跳跃，S/↓ 下蹲，Shift 冲刺，R 重试，F1/右上角选房，Esc 菜单。
