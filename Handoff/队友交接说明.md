## 快速上手指南

1. **打开工程**：
   - 打开 Unity Hub，点击 **Add > Add project from disk**，选中本项目根目录。
   - 使用 **Unity 6000.6.4f1** 打开工程。首次打开后 Unity 会自动读取依赖并完成资产导入。
2. **运行体验**：
   - 在 Project 窗口中展开 `Assets/Scenes/`，双击打开 `MainMenu.unity`。
   - 点击 Unity 编辑器上方的 **Play** 按钮。
   - 点击主界面上的 **新游戏**，即可按顺序体验前三关的完整可玩 Demo！
3. **编辑器常用菜单功能**（位于 Unity 顶部菜单栏 `MiniGame`）：
   - `MiniGame > Rebuild generated scenes`：从纯代码配置重新生成全部 4 个原型场景（注意：如已手工调整美术摆件，建议提前备份场景）。
   - `MiniGame > Validate generated scenes`：自动化验证当前场景的 UI 绑定、检查点地面安全性、机关与通关触发链条。
   - `MiniGame > Build Windows PC`：自动化运行校验并构建生成 Windows 独立可执行游戏包（输出至 `Builds/Windows/MiniGame.exe`）。

## 游戏操作方式

| 操作按键 | 功能描述 |
| :--- | :--- |
| **A / D** 或 **左右方向键** | 角色左右平滑移动（支持地面、冰面不同摩擦与空中微调） |
| **W** 或 **空格键** | 跳跃（可从地面跃上高台） |
| **S** 或 **下方向键** | 下蹲（角色碰撞体高度减半，可穿过低矮通道） |
| **Shift**（配合方向键） | **八方向冲刺**（无按键时沿当前面朝方向横向冲刺；首次冲刺免费，后续消耗充能槽，最多 3 槽） |
| **Esc 键** | 打开 / 关闭游戏内暂停菜单（可在暂停界面调节音量、切换全屏或返回主菜单） |

## 前三关核心玩法与机制详解

每个关卡均严格按照策划案分为 **慢节奏探索收集阶段** 与 **快节奏 AI 追击逃生阶段**：

### 关卡 1：物理关卡（主题：力学与热力学）
- **玩法流程**：
  1. 出生后先在前半段区域探索，收集普通 Token（+100分/充能冲刺槽）与大 Token（+1000分）。
  2. **冰面滑行**：踏上浅蓝色冰块，摩擦力显著降低；在冰块上停留 1 秒后冰块融化，离开 3 秒后重新结冰。
  3. **热控方块**：踩踏可切换房间温度（寒冷/炎热）。炎热状态下所有冰块保持融化；寒冷状态下重新冻结。
  4. **喷气装置与电磁炮**：喷气装置将玩家强力上抛；电磁炮踩上后进入匀加速导轨并猛烈弹射抛出！
  5. **AI 激活**：触碰 AI 启动装置，消耗所有 Token 启动追击 AI。投入 Token 越多，AI 速度与难度系数越高。
  6. **引领 AI 拾取收藏品**：紫色稀有收藏品（+10000分）受保护，玩家需精妙引狂暴 AI 靠近至 5m 以内才能成功拾取！
  7. **躲避 AI 技能**：本关 AI 专属技能为 **超强爆发突刺 (Burst Dash)**。
  8. **抵达终点**：AI 激活后前往终点 Exit，结算通关奖励（+50000分），进入第 2 关。

### 关卡 2：高数关卡（主题：微积分与几何变换）
- **玩法流程**：
  1. **积分 / 求导方块**：踩踏后在【积分】与【求导】模式之间切换。积分模式下，散落在空中的零散方块平滑聚拢为通行平台；求导模式下，方块拆散回原位。
  2. **旋转危险方块**：避开持续旋转的红色危险方块，其外力会将接触到的玩家与 AI 猛烈击退打飞。
  3. **AI 专属技能**：本关追击 AI 技能为 **微积分力场牵引 (Calculus Drift)**，近身时会将玩家反向拉向自身！
  4. 引领 AI 拾取高难度收藏品后抵达终点通关。

### 关卡 3：水课关卡（主题：考勤、巡查与 Deadline）
- **玩法流程**：
  1. **考勤签到大门**：前半段分布有 5 个签到方块，玩家全部踩中完成 5 次签到后，通往逃生区的签到大门（Attendance Door）开启！
  2. **巡查老师**：沿巡逻路线移动的老师，玩家触碰会扣除 500 积分；巡查老师走过**清醒方块**时会将其唤醒为穿透状态，玩家穿过可获得移速爆发 Buff！
  3. **激活 AI**：穿过签到大门触碰启动装置，激活追击 AI；本关 AI 专属技能为 **Deadline 压迫光环 (Deadline Pressure)**，近身时光环会使玩家减速。
  4. **AI 靠近开门机制**：终点通关大门（AI Door）由 `DistanceTriggerMechanism` 锁定，玩家一人无法打开，必须在逃亡中引领 AI 靠近开关（<5m），大门开启，逃入终点通关全部关卡！

## 检查点与防挫败存档系统

- **安全检查点**：每关设有多个位于坚实地面的检查点旗帜。
- **死亡与即时回滚**：当玩家跌落虚空或被 AI 捕获时，在最近检查点复活，并获得 1.5 秒无敌保护时间；同时自动回滚该保存点时的分数、Token 持有量、冲刺次数、拾取物状态及所有机关状态（门开闭、签到数、冷热状态等）。
- **全局存档与读档**：
  - 通关与最高分自动持久化在本地 JSON 存档。
  - 主菜单根据存档自动高亮最新关卡、标绿已通关关卡、锁定未通关关卡。

## 其他开发者二次开发指南

本项目设计遵循极简高内聚、方便扩展的原则，适合作为原型基础继续迭代：

1. **美术素材替换（换皮）**：
   - 当前原型使用 `Assets/WhiteSquare.png` 色块占位验证玩法。
   - 所有玩家、AI、敌人、机关方块、Token 均挂载了标准的 `SpriteRenderer` 组件。
   - 开发者可直接在场景中选中 GameObject，将制作好的角色 Sprite、贴图或动画拖拽替换到 `SpriteRenderer.sprite`，无需修改任何核心代码。
2. **手感与数值微调**：
   - 玩家手感：在 `PlayerController.cs` 的 Inspector 中直接调节 `moveSpeed`（移动速度）、`jumpVelocity`（跳跃高度）、`dashInitialSpeed`（冲刺速度）、`dashDuration`（冲刺时长）等。
   - AI 难度：在 `EnemyAI.cs` 中调节 `baseChaseSpeed`（基础追击速度）、`skillCooldown`（技能冷却）、`skillTriggerDistance`（近身触发距离）等。
3. **添加新关卡（如 Level 4）**：
   - 在 `LevelManager.cs` 中将 `TOTAL_LEVELS` 改为目标关卡数。
   - 参考 `MiniGameAutoSetup.cs` 中的 `BuildLevel` 方法添加新关卡的机关摆放与逻辑。
   - 将新场景加入 Build Settings 即可自动纳入主菜单与通关流转。
4. **添加新机关**：
   - 继承 `BaseBlock` 或 `InteractiveBlock`。
   - 若机关需要支持死亡后回滚，只需在类上实现 `ICheckpointState` 接口并实现 `CaptureCheckpointState()` 与 `RestoreCheckpointState(object state)` 即可。
