# 《AI 大人，拜托了》队友交接说明

## 交付状态

- 目标平台：Windows PC；Unity 版本：**6000.6.4f1**。
- 同目录的 `MiniGame_Unity工程_源码包.zip` 是可编辑的 Unity 工程源码包，供程序、关卡和美术队友协作使用。
- **当前尚无 `MiniGame.exe`。** 2026-10-18 的 Unity 批处理已连接 Licensing Client，但因缺少 `com.unity.editor.headless` 许可退出（返回码 198）。场景尚未由编辑器生成，因此没有完成 Play 模式跑关或 Windows 构建。请勿将此目录标为可发行游戏包。
- 已完成的机器检查：旧版/新输入分支 C# 编译均为 0 错误、0 警告；速度叠加回归 16 项断言通过；三关几何、跳跃距离及检查点静态检查通过。这些检查不等于实际可玩性验收。
- 本轮已补充机关检查点回滚、加减速独立计时、热控重结冰、电磁炮死亡取消及 AI 引用缓存，详细变更见 `Validation/OPTIMIZATION.md`，接手后应先执行 `Validation/PLAYTEST.md` 的新增回归项。

## 接手工程

1. 解压 `MiniGame_Unity工程_源码包.zip` 到一个**可写的独立目录**，保留 `Assets`、`Packages`、`ProjectSettings` 的目录结构。
2. 在 Unity Hub 用 Unity **6000.6.4f1** 打开解压后的工程，等待首次导入与脚本编译结束。编辑器会自动生成 `Assets/Scenes/MainMenu.unity` 和 `Level1`～`Level3` 三个场景，并注册到 Build Settings。
3. 如果首次导入后场景未生成，先查看 Unity Console 的第一条错误；修复后用菜单 **MiniGame > Rebuild generated scenes** 重新生成。此命令会覆盖四个生成场景，接入美术或手工改关后不要直接执行。
4. 在 Unity 中运行 **MiniGame > Validate generated scenes**。通过后打开 `Assets/Scenes/MainMenu.unity`，进入 Play 模式，从新游戏开始跑通三关。
5. 完成下方验收后，运行 **MiniGame > Build Windows PC**。成功时会生成 `Builds/Windows/MiniGame.exe`、`MiniGame_Data` 文件夹，并把本说明复制到同一目录。交付可执行版时须保留 exe、Data 文件夹及 Unity 生成的其他依赖文件。

## 游戏操作与流程

| 操作 | 按键 |
| --- | --- |
| 左右移动 | A / D 或方向键 |
| 跳跃 | W / 空格 |
| 下蹲 | S |
| 八方向冲刺 | Shift，配合方向键；无方向时朝面向方向冲刺 |
| 暂停 / 继续 | Esc |

关卡依次为物理、高数、水课。先收集 Token，触碰装置消耗持有的 Token 并启动 AI，再逃往出口。收集更多 Token 会提高 AI 难度。三关各有独立机关；检查点记录分数、Token、冲刺和拾取状态。主菜单可开始新游戏、继续已解锁关卡，最高分独立保留。

## 美术队友接入

当前场景只使用纯色方块作为**占位素材**，没有正式美术。请在场景生成并保存后，替换场景对象的 `SpriteRenderer.sprite` 和 UI 图片，按新素材调整 Pixels Per Unit、对象缩放与碰撞体。玩家、AI、机关、拾取物、门、地面与 UI 都有独立对象，脚本主要位于 `Assets/Scripts`；场景生成器位于 `Assets/Editor/MiniGameAutoSetup.cs`。

接入后请保存场景并备份工程；再次执行 **Rebuild generated scenes** 会覆盖场景内的美术摆放和手工关卡修改。正式字体、音效、动画、反馈特效和菜单视觉仍待团队接入。

## 必做验收

1. 在 Unity Console 无异常的前提下，从主菜单连续通关三关，确认新游戏、继续、关卡解锁、结算与最高分。
2. 每关至少测试启动 AI 前后、两处检查点、死亡复活、拾取回滚、冲刺次数与 AI 追击；确认未启动 AI 时不能通过出口。
3. 分别测试物理关冰面、热控、喷气和电磁炮；高数关聚散方块和旋转障碍；水课关五次签到、教师、AI 靠近开关及大门。
4. 在 1280×720 和 1920×1080 检查菜单、HUD、暂停、音量和全屏；再运行 Windows 构建版重复核心流程，测试重启后的存档。

详细步骤见源码包内 `Validation/PLAYTEST.md`。当前三关仍是短原型；完成真实玩家试玩、内容扩充、难度调整、美术音频接入和 Windows 兼容性测试后，再评估商用发行。
