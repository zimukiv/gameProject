## 拉取与启动

先保存自己工作区的修改，再在现有仓库执行：

```sh
git fetch origin codex/roomlab-handoff-2026-10-26
git switch --track origin/codex/roomlab-handoff-2026-10-26
```

仓库根目录直接包含 `Assets`、`Packages`、`ProjectSettings`。Windows PowerShell 在仓库根目录执行：

```powershell
& .\Tools\RoomLabExactHost\setup-runtime.ps1
```

脚本首次从 Electron 官方 GitHub Release 下载 Windows x64 **44.5.1**，验证固定 SHA-256，解压到忽略目录 `.roomlab-runtime`，再覆盖本分支的玩法源码、关卡和素材。无需 npm install。已有兼容运行器时可传 `-ExistingRuntime '完整的RoomLabRuntime目录'`，避免重复下载。脚本可能受到本机 PowerShell 执行策略限制，按团队的脚本运行方式执行。

Unity Hub 添加仓库根目录，使用 **Unity 6000.6.4f1**。打开 **`Assets/RoomLabExactConnected/RoomLabExact.unity`** 后 Play。编辑器优先寻找仓库内 `.roomlab-runtime`，不依赖提交者的 D 盘路径。

## 当前玩法与完成内容

- 权威关卡来自 [第一大关 · 物理 DDL.zip](Inputs/第一大关%20·%20物理%20DDL.zip)，共 **11 房间、10 条连接**。前十出口切换房间，最后出口通关。ZIP SHA-256：`66a94cb2cbe1512ea2e76a8282075498bb4f2dc0c0dc39c3529d2cdd733b8667`。
- 当前使用 RoomLab 2.5.2 JS 核心与绘制；Unity 负责输入、菜单和显示画面，经本机 TCP 与隐藏 Electron 运行器通信。不是旧 C# PlayerController/EnemyAI 的玩法。
- 用户要求的水平冲刺已完成：左/右 + Shift 指定方向，没有左右输入时按角色朝向。原速度、时长、免费落地首冲、最多三次周期冲刺和付费库存保留。
- 最新冲刺资源规则已覆盖上述首次交接的三次周期规则：免费冲刺每次落地恢复，可不限累计次数使用；落地前最多再用一次付费冲刺，库存仍上限 3。落地只恢复机会、不补库存；跨房继承 `paidDashUsed`，死亡重试重开机会并等待 0.5 秒。Unity HUD 已重建，原代码和测试见 Bug 日志“功能-003”。
- Esc 打开暂停菜单，菜单只有“退出游戏”按钮；再按 Esc 继续。菜单内屏蔽玩法输入，退出时关闭隐藏运行器。
- 复活或 R 重试后增加 0.5 秒静默缓冲；角色、AI、机关及计时冻结，期间无法操作，不显示准备界面或倒计时。缓冲期间跳跃/冲刺事件丢弃，重复 R 不重新计时。Esc 可暂停内部计时；正常开局/跨房不等待。统一计时在 Engine 中，见 Bug 日志“功能-001”。
- 普通水平移动改为约 0.1 秒从零加速到原最高速度，持续按住后匀速；松键立即停止，反向重新起步。地面/空中/蹲行及纯竖直喷射后的水平控制使用此过程；冰面、冲刺和横向弹射保留原分支。参数 `settings.performance.moveAccelerationTime`，默认值在 `src/project/performance.cjs`，验证见 Bug 日志“功能-002”。
- 已修复导轨滑行跳过 Token 拾取检测的问题。错误原代码、原因、修复与证据见 [Bug 修复日志](../Validation/BUGFIX_LOG.md)。
- 后续尖刺调整：统一改为底部红色半圆，1×1 格外观半径 14px，危险半径 11px，留 3px 容错；不再整格阻挡/判死。共享几何在 `src/project/spikes.cjs`，实际问题原代码和 24 项判定验证见 Bug 日志 BUG-002。
- 后续朝向修正：225 个尖刺按墙面和附近排列保存 `params.direction`；半圆底边贴墙，12 个悬空尖刺随组统一方向。外观与危险区同步旋转，四向判定共 96 项通过。27 个既有地形重叠位置保留并单独记录，详见 BUG-003 和 `Validation/LatestRoomLabEvidence/spike-directions.json`。原始 ZIP 不改，运行项目仅新增尖刺朝向字段。
- 原核心的 AI 投入档位、累计融冰与再生、轨道终点角度/脱离、触发与死亡回退继续保留。

操作：A/D 或左右移动；空格/W/↑ 跳跃；Shift 左右冲刺；S/↓ 蹲下；R 重试；Esc 菜单；F1/右上角选房。

2026-10-26 连冲输入修复：Unity 现在发送按帧采样的 `samples: [{dt, input}]`，运行器 `src/runtime/input-steps.cjs` 顺序消费事件。禁止恢复原先的 `{...c.input,...edges}` 循环：清空 edges 后 c.input 中的 true 仍会在每个物理步重复触发，一次 Shift 就耗尽免费和付费两次机会。也不要把多次 Shift 合并为 Unity 端的单个 edgeDash。详见 BUGFIX_LOG 的 BUG-004；新增 `verify-dash-input.cjs`，真实运行器现有 346 项对照与实际第一房间空中连冲资源断言。当前本机试玩已重建同步，旧分发 ZIP 未更新。

2026-10-26 温控切冷立即结冰：`Engine.setTemperature()` 在同次调用同步实际由热变冷的冰块，调用冰插件 `onTemperatureChange()`，立即恢复实体并清零融化累计和再生成倒计时。持续冷态下踩踏融化后的原再生成间隔仍保留；重叠区仍受热时不误冻。新增 `verify-instant-freeze.cjs`，4 个装置/317 个冰块状态检查通过；原错误代码及证据见 BUGFIX_LOG 的 BUG-005。本机试玩 JS 副本已同步，重启加载。

2026-10-26 开发者模式：Esc 菜单勾选开发者模式后可开启锁血，默认关闭，仅本次运行有效。协议 `developer: {enabled, lockHealth}` 同步到引擎，暂停/切房/重试保留；关闭模式会清除锁血。锁血免疫尖刺与 AI 抓捕（含 Token 偷取），掉落回当前入口但不重置资源/机关/死亡次数；R 手动重试仍有效。新增 `verify-developer-mode.cjs`，实际桥接扩为 350 项，当前本机试玩菜单已重新构建。详见 BUGFIX_LOG 功能-004。

后续菜单扩展：新增 `RoomLabKeyBindings.cs`，Esc 菜单支持 7 项操作的主键/备用键及本机保存，读取必须使用 GameInput 的 Exact 方法；原别名读取仅供历史原型。58 项键位检查由 `RoomLabKeyBindingsCheck.Run()` 在连线版构建前执行，不修改玩家偏好。

开发者协议现为 `{enabled, lockHealth, flight}`。飞行使用现有左右/跳跃/下蹲映射，穿墙悬停，不触发拾取、机关和出口，关闭时恢复安全位置与正常物理。地图预览协议为 `mapView: room|course`、`previewRoom`、`mapZoom`、`mapPanX/Y`；Frame 返回 `mapRooms` 卡片坐标及预览房间名，坐标原点在游戏画面内（Unity 显示时 y 加 110）。预览只读、期间不推进世界，清空输入边沿。`developer-map.cjs` 绘制全房间视野及 11 房间/10 连接总览，其他房间全图是布局预览。新增 `verify-flight-map.cjs`，实际桥接已扩为 359 项，当前本机试玩已重新构建同步。使用、限制和证据见 BUGFIX_LOG 功能-005/006。

DDL1.3 适配新增 `common.checkpoint`，触碰时通过 `captureCheckpoint()` 保存安全位置及当前资源/收集/机关快照，`retry()` 用带存档位置的 `loadRoom(..., respawn)` 恢复，AI 从存档位置附近重建追逐。快照仅属于本次运行的当前房间；飞行不触发存档，地图预览不修改它。新增 `verify-checkpoints.cjs`，覆盖全部 7 个点及 21 条死亡路径；实际运行器验证扩为 362 项。源 ZIP 中 AI追逐1 的区域 `x=-1,w=44` 在运行副本裁为 `x=0,w=43`，地图内覆盖相同。不要直接用未经合并的原包覆盖运行数据，否则会丢失 2 秒冰块/尖刺朝向并恢复越界错误。

原架构仍是 JS 核心嵌入；如后续希望完全改为原生 Unity 玩法，应作为独立迁移任务规划。
