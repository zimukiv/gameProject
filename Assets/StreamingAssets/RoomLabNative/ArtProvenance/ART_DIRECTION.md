# 第一大关物理 Demo：美术源素材与接入约定

## 依据与优先级

最新用户明确以 `G:/project null/minigame策划案 (3).docx` 和本会话属性/素材截图为内容依据。已读 DOCX：大学生把论文交给 AI、收集 token 充能、AI 追逐、关卡快慢两段；第一大关物理是科幻风，冷蓝/热橙滤镜。DOCX 美术需求段为空，未指定具体角色立绘。本批仅第一大关，不生产高数、水课或教师。

截图经主代理转交的物理项约束：A0001 电磁炮对应位置炮管背景细节、左右朝向、中间横向轨迹和平台；A0002 热反应方块为一个方块带中央操作台；A0003/A0011 冰蓝完整/裂痕；A0004 喷气装置可辨识即可。电磁炮炮管装饰与可站立轨道需要分别接入；不要用大炮外形覆盖或改变关卡碰撞范围。

用户两份参考文档是美术参考，不是额外工程操作授权。技术尺寸以 `美术素材清单_v4_像素风锁定版.md` 优先，覆盖旧 `07-美术素材规格与首批任务单.md` 的 128 PPU：32 PPU，32×32 格，角色32×64、基线底上8px、pivot(0.5,0.125)、默认右向、Point/无压缩/无 mipmap；目标640×360。这里记录目标，不宣称生成大师图已经精确符合。

## 本次新增的美术设计选择

精致16-bit手工像素感，校园实验室中的暖色学生与冷色 AI 相互区分。学生：中性短深蓝发、芥末黄夹克、奶油内衬、深蓝裤、珊瑚背包。AI：浮空 CRT 论文助手，深青/淡紫外壳、青色表情。实验室：深靛蓝和灰青，铜色平台包边，青蓝冰与冷控、橙珊瑚热控、薄荷喷流、青紫电磁轨。建议调色参照：#172238 #263B50 #466B73 #9EBDB5 #E8D9AB #D49A40 #BD6856 #74D9D9 #A99EC3；实际源图未做严格索引色限制。

背景低对比，大学楼远景、窗、黑板、桌灯和仪器；下部与中央留给动作。主界面手机/论文待办属于后续 UI 主题，本批未生成手机 UI。禁止把文字画进纹理，字体由代码集成另行处理。

## 真实规格偏差与接入门槛

- 生成器没有严格遵循请求的1024格网：所有方形图实际1254×1254，AI还是不均匀五行。`ART_MANIFEST.json` 使用实测源像素矩形；禁止按假设的8×4或4×4直接切整图。
- 玩家只有22个可辨识姿势。dash 第三槽明确复用 dash01，动画槽可凑23但不是23张独立帧。death 后两帧低透明碎片须保留，不能全图统一alpha128硬切。
- `sourceRect` 是可消费裁剪包络，`alpha128BBox` 是包络中实际主体测量，`sourceAnchor` 是源图坐标。角色锚点为估计的行基线；稳定足部对齐、边缘散点清理仍需代码接入验证。玩家 fall/dash 原图宽姿势局部相邻交叠，必要时做确定性主体连通域遮罩，避免邻帧噪点。AI技能有独立光效碎片。
- 角色不能每帧简单以 bbox 居中，否则会漂移。应使用固定注册锚点、最近邻采样，生成目标32×64画布，底上8px基线；主体比例目标学生约26×42/AI29×42，本批原图仍需归一化验证。未伪称原图为精确逻辑像素成品。
- 当前画风有细碎高光与半透明边缘，不完全满足严格有限色板/无抗锯齿。Unity 接入可做确定性最近邻与alpha整理，但需要原生截图复核。不得以代码形状替代这里的实际图案后宣称已使用生成美术。
- 地形拼接未验收，填充图带铜边；平台需匹配顶边、两端和中段。原图裁剪体积不得改变 RoomLab 2.5.5 的 x/y/width/height/碰撞。
- 喷气 active 图有合并喷流，应保留固定喷口底座并将喷流视为非碰撞光效。配对机关状态共享画布与底部锚点，不能单独拉伸造成状态跳动。
- 背景实际1672×941，接近16:9但不等于目标1920×1080；用最近邻适配640×360。左右无缝未证明，当前适合单房间静态背景。没有独立中景层或可编辑分层。

`ART_MANIFEST.json` 含真实尺寸、alpha范围、SHA256、矩形、逻辑目标、源锚点、动画顺序/FPS和偏差。矩形坐标左上原点，Unity 转换 y=H-y-h。`build_manifest.py` 只测量PNG并写元数据，不生成/修改美术。`ALPHA_ANALYSIS.json` 为前六图的原始连通域诊断，manifest 才是最新交付清单（含第七张电磁炮）。

本子任务仅交美术源和测量，不宣称 Unity 已切帧、试玩性能已通过或 RoomLab 导入已验收；这些由原生接入与独立验收阶段证明。
