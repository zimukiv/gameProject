# 《AI大人，拜托了！》交付包

## 目录

- `素材/`：已整理的标准化素材与 UI
- `预览/`：主界面、素材预览工具、暂停页、结算页
- `说明/`：程序修改清单与对齐说明
- `预览图/`：关键页面截图

## 预览入口

- 主界面：`预览/主界面UI预览/index.html`
- 素材预览工具：`预览/素材预览工具/启动素材预览.cmd`
- 手机暂停页：`预览/暂停页mockup/phone_pause.html`
- 手机结算页：`预览/暂停页mockup/phone_result.html`
- 纸张版暂停页：`预览/暂停页mockup/index.html`
- 纸张版结算页：`预览/结算页mockup/index.html`

HTML 预览需要本地服务器打开，不能直接双击 `file://`，素材预览工具自带启动脚本。

## 重点说明

1. 暂停页和结算页的文字全部是 TMP 叠加，底图没有烘焙文字。
2. 结算页文字锚点见 `说明/结算页对齐说明.md`，不要凭感觉摆放。
3. 中景函数/算式、地块数字的改动见 `说明/给程序同学的修改清单.md`。
4. 主界面和暂停/结算统一采用手机 UI；纸张便签作为手机内的内容层保留。
5. 冰冻、热浪、喷气特效均为独立帧，按 README/文件名中的帧序接入。
