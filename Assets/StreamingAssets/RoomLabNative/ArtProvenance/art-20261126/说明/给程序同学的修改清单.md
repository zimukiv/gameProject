# 给程序同学的修改清单

> 说明：以下主要是**程序实现**的调整项，预览页不一定全部体现；打包时必须保留本文件。

## 1. 中景：函数与算式

### 现状
- 函数和算式目前是在**单个背景格子**里运动、显示的。
- 左右两侧容易出现相同或高度相似的函数。

### 需要改成
1. **算式在整个屏幕范围运动**
   - 不绑定某一个背景格；
   - 可以在屏幕任意位置出现、移动、消失；
   - 不要被单个 cell 的裁剪区域限制。

2. **函数可以超过一个背景单元的大小**
   - 函数曲线允许跨越多个格子，甚至超出屏幕边缘；
   - 不要按单格尺寸裁切函数。

3. **函数用彩色线条绘制**
   - 建议使用低饱和的青、蓝紫、金、珊瑚色系；
   - 颜色要能和深色背景区分，但不要抢主体；
   - 同一条函数保持统一颜色，不同函数可换色。

4. **左右函数不要重复**
   - 左侧和右侧使用不同的函数池；
   - 同一房间内左右不要出现同一个函数；
   - 跨房间也尽量避免连续重复，建议按 room seed 抽取；
   - 如果函数数量不够，至少做到“左右不同 + 相邻房间不重复”。

### 实现建议
- 中景函数放到独立的**全屏 Canvas / Overlay**，不要挂在地块节点下；
- 函数作为独立对象生成，随机起点、速度、方向、生命周期；
- 用 LineRenderer / UI 线条绘制，关闭格子级裁切；
- 随机池按左右分组，使用 `seed` 保证可复现且不重复。

## 2. 地块上的数字 / 算式

### 需要调整
1. **颜色稍微浅一点**
   - 当前对比偏重，容易抢画面；
   - 建议降低 1–2 档明度/透明度，保持可读但不刺眼；
   - 不要浅到看不清。

2. **减少关卡之间的重复**
   - 当前竖式和数字在关卡间重复很明显；
   - 需要按关卡 seed / 房间 seed 随机；
   - 避免相邻关卡出现同一竖式或同一组数字；
   - 扩大数字/算式池，至少保证连续 3 关不重复。

### 实现建议
- 如果数字/算式是程序生成：按关卡 seed 抽取，记录已用组合；
- 如果是预渲染贴图：至少制作多组变体，由程序按关卡选择；
- 左右、上下地块不要使用完全相同的数字组合。

## 3. 验收标准

- 中景算式可以跨屏运动，不被单格裁切；
- 函数曲线能跨越多个格子，颜色清晰；
- 同一房间左右函数不同；
- 连续 3 关不出现明显相同的竖式/数字组合；
- 地块数字颜色比当前浅，但仍可读。
