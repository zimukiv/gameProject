# 原型规则与范围

规则优先级：本次交接中已确认的规则 > 策划案正文 > 批注候选。本文记录 T01 开工时的取舍，不修改原策划案。

## 已确认

- 新进入每关 token 为 0。AI 启动前后均可冲刺，实际执行时扣 token，不转换为预存次数。
- 启动 AI 消耗剩余全部 token，赠送一次免费冲刺。免费机会优先使用，也占用本次腾空次数。
- 一次腾空最多冲刺三次。落地只重置连续次数额度，保留 token 和未用免费机会，不补充资源。
- 免费机会用完且 token 不足时不能冲刺。
- 普通 token +1、大 token +5、冲刺消耗 2 是原型建议参数，交由 B 配置，尚非最终数值。
- 先完成一张短地图：探索、收集与跑跳、启动 AI、追逐、必经引导机关、可选收藏挑战、终点提示。
- 体验以连续跑跳为主，少数位置通过减速、回跳或绕路引导 AI。

## 正文中的长期设计

三关、25–50 分钟体验、设置与主菜单、关卡解锁、全局及临时存档、主题机关和正式美术是长期目标，不是这轮交付。
正文积分示例为普通 token 100、大 token 1000、收藏品 10000、通关 50000；等 T03/T06 与 B 确认配置，T02 不实现积分。
正文“冲刺最多蓄积三次”“首次免费”由上述确认规则覆盖；不建立另一套冲刺储存状态。

## 待验证建议

固定 AI 参数、预设路线及玩家触发标记，碰 AI 或掉出地图死亡，探索与追逐入口各一个检查点；死亡一致恢复资源、AI、机关和收集物。这些等 T04/T05 再确认体验，不在 T02 提前建立正式状态系统。

T02 遵循正文先支持 A/D 与方向键移动、空格/W 跳跃。T03 时需明确 W 跳跃与向上冲刺的输入优先级。蹲下、变跳高、跳跃缓冲及土狼时间留待手感验证。
