# Windows PC 跑关验收单

在 Unity Hub 启动的 Unity 6000.6.4f1 中先执行 **MiniGame > Validate generated scenes**。此检查通过后，从 `MainMenu` 进入 Play 模式，按以下顺序测试。每项应在 Console 无异常的前提下通过。

## 全局流程

- 清空/新建存档时仅新游戏可用，第一关高亮；开始游戏后退出到主菜单，继续游戏可返回第一关。已通关关卡可选，未解锁关卡不可进入。
- A/D、W/空格、S、Shift、Esc 的操作与提示一致；Shift 只沿横向冲刺，W/S 不改变冲刺方向，无横向输入时沿面朝方向。开局 0 次，每收集 3 Token 充满 1 次，最多储存 1 次；满充后不囤额外能量，使用后从 0/3 重新充能。AI 启动不赠送冲刺，落地不补充资源。HUD 只有一个槽并显示充能进度。
- 暂停后玩家和 AI 都停止，音量与全屏切换可操作；继续后恢复。1280×720 与 1920×1080 下菜单、HUD、按钮均完整可见。
- 收集普通 Token 增加 100 分，大 Token 增加 1000 分，收藏品增加 10000 分，通关增加 50000 分。最高分在新游戏后仍保留。

## 每关都要测试

1. 先触碰第一个检查点，再收集 Token 并启动 AI。确认 Token 被全部消耗，HUD 切为追逐阶段，AI 延迟约 1 秒开始追击。
2. 在到达第二个检查点前故意死亡。确认回到第一个检查点，分数/Token/冲刺与拾取物回滚，重力正常，启动装置可再次触发。
3. 高数/水课再次启动 AI，触碰追逐中的检查点后故意死亡，确认回到安全地面、保持追逐阶段并获得短暂复活保护。物理关现在两个检查点都在 AI 启动前，死亡应回到喷气口前的小旗子，恢复探索阶段，重新登台后可再按 E 启动。
4. 尝试从未启动 AI 的状态进入出口：不得通关。启动后进入出口：只结算一次，显示通关面板；按下一关或返回主菜单进入正确场景。
5. 将 AI 引至紫色收藏品附近，再拾取。AI 远离时不得拾取。

## 检查点与速度效果回归

- 水课：保存检查点后签满五次、打开门，再在下一个检查点前死亡。签到数、方块颜色、大门位置、AI 开关和清醒块应全部回到保存时状态；重新签到仍可开门。保存已开门的检查点后死亡，门应保持开启。
- 物理/高数：在保存后切换冷热或积分/求导，再死亡。冰块碰撞体、热控颜色、受控平台位置应回滚；保存时正在移动的平台应继续完成运动，限时平台应从保存的剩余时间继续计时。
- 启动 AI 后在追逐前的检查点复活，HUD 应重新显示“探索 · 收集 Token”；追逐中的检查点复活应显示追逐提示，AI 技能协程应停止并重新冷却。
- 在移动平台上死亡，复活后玩家不得继续随平台漂移；从侧面撞平台不得被附着。
- 连续穿过同一个清醒块只刷新加速时长；同时受到 AI 减速时，先到期的效果独立消失，全部结束后速度恢复。效果持续期间暂停，再继续，剩余时长应保留；死亡应立即清除全部效果。
- 热控切为热态后，等待超过 3 秒，冰块应保持融化；切回冷态后冰块重新出现，站立超过 1 秒也不应自行消失。A/B 显示必须同步，踩上控制器不得切换，仅靠近按 E 操作。
- 电磁炮导轨期间按方向键和 Shift 不应覆盖导轨运动；途中死亡后等待至少一秒，角色应留在检查点，不能被旧协程拉回轨道；弹射后恢复角色配置的重力。
- 当前工程使用旧版输入。安装 Input System 包并切换输入后，玩家、Esc 和手动交互 E 都需再次验收；新生成场景的 EventSystem 应使用对应模块。已生成场景切换输入时，应同步替换 EventSystem 的输入模块，避免覆盖团队编辑的场景。

## 持续接触、分数与固定物理步回归

- 复活后在保护时间内让 AI 接触并持续重叠，不要离开范围：1.5 秒保护结束后应再次死亡。Trigger 危险区和实体 Hazard 碰撞也应重新判定；保护期间不得每帧复活。
- 在已结算总分为 100000 的存档中进入水课，被老师扣 500 分后正常退出。重启后已结算分数仍为 100000；重新进入关卡与不重启直接重进关卡应得到相同起始分数。当前分数、最高分与已结算分数应分别保持其含义。
- 将 Trigger 类型 AI 引向旋转机关，应被击退约 0.4 秒后才恢复追击；在 AI 爆发技能期间碰撞，旧技能不应覆盖击退。实体玩家也应被击飞，击退后死亡复活不得保留旧速度。
- 分别限制渲染到 30/60/144 FPS。短按跳跃和 Shift 都只能触发一次，不能因同帧多个物理步重复消耗冲刺；高帧率短按不能被下一物理步漏掉。暂停、复活或进入导轨后，旧按键不得在恢复控制时补发。
- 在空中无碰撞环境，配置冲刺初速 25、减速 50、时长 0.22 时，理论位移约 4.29 米；比较不同渲染帧率和固定步长。物理碰撞、移动平台跟随和实际手感仍需独立验收。
- 连续拾取 Token 时观察存档日志，普通实时分数修改应合并为最多每秒一次写盘；暂停、通关、返回菜单与正常退出立即刷新。重启检查最新最高分；首次新游戏和旧版存档均需验证。
- 连续拖动音量滑块应立即改变听感，但写盘最多每 0.5 秒合并一次；拖动后立即暂停或退出，再重启应保留最后音量。全屏切换即时保存，不能因同步 Toggle 再次触发反向切换。
- 移除测试关卡的 Build Settings 注册后尝试加载，应明确报错，并保留原关卡索引和分数。验收后恢复注册。

独立逻辑回归：`dotnet run --project Validation/RegressionChecks/RegressionChecks.csproj`，当前覆盖速度效果、分数规范化、输入缓存、冲刺位移、单槽充能、写入调度与复活保护，共 76 项断言。这不执行 Unity 碰撞回调、UI 或磁盘 API，也不替代以上运行验收。

## 专属机关

- 物理：开局为热态，A 处按 E 降温生成三段冰阶；跳上永久高台，在 B 处按 E 升温融开冰墙，继续到 AI 启动器。冰块没有打滑、踩踏融化和计时恢复。掉到下方可以返回 A 重试，两个控制器与检查点在永久地面上；冷热状态随检查点一起回滚。
- 物理喷气口试玩版：进入前可见向上流动的箭头和“喷气口 / A、D 左右调整”标识；向右跑入喷气口时保留横向惯性，喷起后立即按 A/D 可调整，Shift 仍按原有资源规则工作。同一次停留不反复喷射；离开后重新进入、死亡复活后重新进入均能再次喷射。
- 物理喷气路线：喷气前检查点为小旗子，保存时显示“检查点已保存”。喷气口上方没有紫色移动平台，持续向右跑入喷气口应自然落在右上固定高台并收取大 Token。高台 AI 核心接触时不启动，按 E 才消耗 Token 开始追逐；暂停时不得启动。离开高台后落上地面直路，再顺路进入电磁炮，无需跳过凸起的实体炮台。
- 物理电磁炮试玩版：入口有“电磁炮”标识，运行时能看到导轨和出口箭头。轨道内保持自动运输，出轨后立即按 A/D 或 Shift 能响应；普通敌人拉扯和高数机关击退仍保留原有短暂控制锁定。
- 物理终点引导：周期平台旁写明“出现 2 秒 / 消失 2 秒”，附倒计时与进度条。最后 0.6 秒橙色闪烁并显示“即将消失”；隐藏时显示虚线轮廓和“暂不可站立 / 恢复倒计时”。暂停时提示冻结，复活回滚后提示应与碰撞一致。上方标记可选收藏和 AI 靠近要求，下方标记直走通关；拾取收藏品后对应提示消失，回滚恢复收藏品时提示也恢复。
- 高数：积分/求导方块使周边块聚合/散开；旋转块击飞玩家与 AI。
- 水课：五个签到块各计一次并打开门；老师碰撞扣 500 分；AI 靠近开关时可开门；清醒块在老师经过后可穿过并加速。

## Windows 构建验收

执行 **MiniGame > Build Windows PC**，确认 `Builds/Windows/MiniGame.exe` 生成。运行打包版本重复以上流程；检查重启后继续游戏与最高分，以及首次启动、切换全屏、退出时无异常。

## 发行前仍需完成

当前关卡几何是短原型，尚未达到策划案的 25–50 分钟时长。需在真实玩家测试中扩展三关内容、校准难度与节奏，接入团队美术和音频，并完成不同配置 Windows 机器的性能与兼容性测试。没有这些结果，不应标记为商用发行就绪。
