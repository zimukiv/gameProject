# 喷气登台与主动追逐试玩版（2026-10-23）

退出 Play 后重新打开 `Assets/Scenes/Level1.unity`，等待脚本编译，再 Play。场景文件已更新，无需运行 Rebuild generated scenes。当前为原型美术。

## 新路线

冷热通道 → 喷气前检查点旗子 → 喷气升空、向右调整 → 固定高台与大 Token → 按 E 启动 AI → 跑下高台落上直路 → 电磁炮 → 终点。

- 移除了这一关喷气口附近的紫色移动平台和两个无用路径点，其他关卡的移动平台保留。
- 固定落台宽 5 单位，位于喷气口右上方，顶面比地面高 4.8 单位；普通跳跃高度约 3.82，喷气高度约 6.13，留下调整余量。喷气初速度改为 19，保留左右控制；喷口正上方不放实体障碍。
- 大 Token 在落台路线附近，引导落点；AI 核心位于同一高台，接触不启动，按 E 才消耗全部 Token 并进入追逐。核心有独立轮廓、AI 字样和说明，暂停时不能启动。
- 物理关两个绿色检查点矩形改为小旗子，激活后变绿，短暂显示“检查点已保存”。第二个旗子移到喷气前安全地面。死亡恢复探索阶段，可重新喷气登台并启动 AI。
- 电磁炮移到高台之后的地面直路，入口改为非实体触发区，避免走路撞上凸起炮台；沿轨道运输，出轨即恢复操作。终点、收藏路线与镜头范围作了对应调整。
- 冷热教学、冲刺资源规则不变；场景生成器同步保持新布局。MainMenu、Level2、Level3 场景文件未改。
