# 电磁载人弹射平台（2026-10-25）

用户要求：站上平台后，由平台载着玩家一起弹射出去。此规则替代旧的“进入非实体区域后，仅移动玩家”的电磁炮行为。

## 试玩

1. 沿物理关原路线启动 AI、下台落地，来到金色平台。
2. 跳上平台，顶部接触后自动载人发射；从侧面碰到、从空中经过均不触发。
3. 平台和玩家一起水平沿导轨加速，不改变玩家父物体或缩放。运输中按空格 / W 可主动跳离，继承平台当时的水平速度，竖直速度使用玩家正常跳跃初速；立刻恢复重力和左右控制，不消耗冲刺。跳离后空平台继续到末端再回位，不能把玩家重新吸回。
4. 到末端后玩家带水平初速度离开，立即恢复 A/D、跳跃/冲刺的正常判定；冲刺仍需要能量。平台停留 0.5 秒后以 8 单位/秒回位，回程暂时无碰撞，到起点重新可站立。
5. 途中死亡或直接检查点复活，平台立即回位、释放玩家；不会在复活后继续运送或拉回玩家。

提示及导轨固定在发射位置，金色实体平台移动。平台与玩家的运动、回程计时均随暂停冻结；运输期间不消耗 Shift 冲刺能量。平台不使用自动融化、消失或移动平台原有的父子附着逻辑。

2026-10-26 按用户要求改为水平弹射：起点 `(41, -2.9)`，终点 `(44, -2.9)`，平台载人期间高度不变，导轨同步显示水平。加速度 30，玩家出轨初速度 `(32, 0)`，不施加向上分量；脱离平台后按正常重力落地。喷气前检查点、Token、AI 速度与冷热规则不变。场景及生成器已同步，无需 Rebuild generated scenes。

## 接口变更（供 B 后续对接）

- `RailgunBlock` 字段名保持：`launchEndPoint`、`acceleration`、`launchExitSpeed`、`launchDirection`。`launchEndPoint` 现表示载人平台中心到达的位置，旧实现表示玩家中心终点。运输从协程改为固定物理步更新。
- `Railgun` 对象新增运动学 `Rigidbody2D`，重力 0，冻结旋转，层级为 Ground（8）。BoxCollider2D 改为实体，局部尺寸 `(1,1)`、偏移 `(0,0)`，对应 Transform 的世界大小 `(2,0.2)`；移除旧的高触发区。仅从顶部踩踏触发。
- 增加只读运行信息 `LaunchStartPosition`、`IsLaunching`，供导轨提示和验证使用。未改事件、存档结构、玩家控制接口、关卡 JSON 或 B 的编辑器工具。
- 2026-10-26 新增 `RailgunBlock.TryJumpOff(PlayerController)`；玩家由电磁平台控制期间仍在 Update 缓存跳跃按键、FixedUpdate 消费一次并调用该入口，其他脚本接管运动维持原规则。暂停时清除跳跃输入，主动跳离后普通空中跳跃不能再次触发；无新序列化字段或编辑器 JSON 变更。
- 复位通过 `OnPlayerDied` / `OnPlayerRespawned` 与组件禁用处理；运输期间不绑定玩家父物体。现有物理关检查点均位于启动前，平台在恢复时重新待发。
