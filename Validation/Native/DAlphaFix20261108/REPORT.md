# dα 末房下行路径修订（2026-11-08）

用户澄清异常主体是方块：脚下那块一离开便飞回顶部，视觉上失去了下一段路。上一版只修角色被携带，未解决路径可读性。before-results.json 保留当前发布版的 50 场景/111 断言基线，证明左右/等待/跳跃扫测并未重现角色飞天，不作为本次关卡设计已好的证据。

## 实现

仅修改当前 deadline-autosave.json 的末房设计。十块 α 纸阶增加 `foldOnReturnAfterSwitch: final-beta`：β 已开启、α 关闭后，在展开位置原位消隐而非向天花板移动；站在该块上时暂停消隐，离开后完成收起。初次 α 展开及其他升降平台保持原规则。这里是透明度消隐，非新增折纸骨骼动画。

永久 dα 平台不动。右侧下行增加三级固定落脚台：x31..33/y22、x33..35/y25、x35..38/y32。少量 γ 符号标注下一段；最终落地再向左到 γ。所有旧对象/平台标识及数量保持。末门新增 states 条件 α=false、β=true、γ=true，以免新增台阶导致绕过预期机关状态。

## 自定义规则

`foldOnReturnAfterSwitch` 为可选字段，必须是本房已声明 switch 的字符串。仅当该开关为真且该平台目标为关闭时，回收位置保持 toX/toY、透明度按已有 progress 下降，progress=0 时不再产生碰撞。该字段适合“先完成展开，再进入回收阶段”的顺序机关，不适合在展开过程中任意切换的电梯。数据导入拒绝数字、对象和未知开关名。
