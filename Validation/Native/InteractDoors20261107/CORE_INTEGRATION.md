# 按互动键进入门：Core 交付说明

当前规则：contact-auto-v1 三章（含原作者物理关）必须在角色矩形与门矩形接触时按下互动键，才会进入。仅接触、站在门中、跳跃经过均不会过门；地面和空中均可互动进入。抵达或读取存档后，原有 0.4 秒进入冷却结束即可再次按互动返回，无需先走开。旧 profile 的门规则保持原样。

本轮删除了自动过门专用的落地/脚底高度判定与返回门 2.5 格免触发范围。NearbyExit 在新版作者物理关也可供界面显示绑定的互动键。存档点触碰仍静默自动保存，存档点按互动仍打开六个手动槽；过门后仍捕获目标入口安全快照，终点仍在结算前捕获可恢复快照。自动历史最新三份的原子文件事务没有修改。

生产修改仅 NativeContactAutosave.cs、NativeGameplayState.cs、NativeNetworkState.cs；每个文件的修改前完整副本在 source-before，带 SHA 的备份索引在 backup-manifest.json。最终三文件哈希在 core-frozen-sha256.json。

新独立专项 CoreChecks/results.json：50/50。通过普通移动、跳跃和单帧互动输入检查三种课程接触不进/E进入/释放后不反跳/再次E返回/空中E；并检查存档旗自动保存、六手动槽、取消保持锚点、水课跨房资源锚点、终点续玩，以及自动三历史与文件替换失败保留原字节。测试为编译当前 Core/Data 的独立夹具验收，不代表三章真人完整通关。

AutoSave20261107/CoreChecks/results.json 的旧 77 项记录原样保留，SHA 已与备份清单核对。它记录此前自动过门语义，不能作为本轮互动门通过的证据。本轮新增的旧 profile 专项检查确认旧 network 仍按 E、旧 physics 仍接触过门；本轮没有覆盖或重写历史冻结 oracle。
